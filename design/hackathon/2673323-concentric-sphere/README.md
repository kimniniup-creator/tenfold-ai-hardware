# 鬼工球／同心球式：玲珑掌托电子侧舱

**这是独立附件的可打印 CAD，不是原鬼工球的改模或完整适配成品。原球直径未取得；默认 60 mm 仅为参数假设。没有实物打印、原球接触面、接口插拔或倒置保持力验证。**

源模型只开放官方 Bambu Handy 打印，许可禁止下载、导出和改编。因此保留原球完整机构，M5StickS3 放入独立侧舱。透明球仅表示空间包络，不含原模型开孔、内层、纹样或网格。该版本适合确认体量与附件工艺，不可据此采购全套或宣布原模型改造成功。

## 机械体验与真实边界

球放在掌托浅座中，掌心托住，拇指从上方和侧面拨动原球可触及的内层。浅座最高 z=10，默认球顶 z=63，上方主体开放。需要完整翻滚、改变孔口朝向时直接取出原球，完整保留它的机械体验。侧舱和球座用一体桥连接，电子件不是唯一把玩内容。

浅座没有倒扣，不夹紧原球，也不保证倒置不掉。两道 9×3 mm 槽供 6–8 mm 宽软硅胶带穿过，携带时环抱原球；把玩前解开带子。带子必须落在实物外层实体带而非孔洞或内层，未经观察不能固定。若没有可靠落带位置，取消带子并使用随身袋。**当前是可手持附件原型，尚未实现可任意翻转的一体化口袋 EDC。**

即使外球包络不相交，也不能证明内部各层不被球座压住。必须把原球放到掌托上逐层旋转，发现任一层停滞立即取下，调整座深或接触区，不能以更大压力强制转动。源球直径未测前，50–80 mm 是脚本允许范围，不是兼容列表。

## 尺寸和避让

- 默认附件外形约 96×62×23 mm；放入假设直径 60 mm 球并计入紧固件后整体约 99×62×69.2 mm。体量明显超过原 PRD；这是本轮保机构的代价。
- M5 坐标：宽沿 X=24，长沿 Y=48，厚沿 Z=15。底部垫 2 mm 闭孔泡棉；实际机身范围 z=5–20。
- 底托开口 24.8×48.8，单边 0.4 mm 余量。顶框下表面 z=20.5，机身顶部留 0.5 mm。顶框开口约 23×48.8，左右仅覆盖机身边缘 0.5 mm。
- 四角螺柱位于机身包络之外。长边大部、两端中部开放，USB/Grove/Hat 和侧键不使用猜测位置的小孔。低围边最高 z=7，若实际插头或按键落在该区域，先改围边高度再打印。
- 这里只核实接口类型与总体尺寸，**尚未验证连接器坐标、插头外壳、屏幕有效区和键帽行程**。装配前使用实物或官方结构文件进一步核对。Hat 大型外设不在包络内。
- 球包络与电子舱最接近处留有空间；原球任意旋转的外包络不变，条件化包络检查通过。软带、手指、线缆、变形及原球内层运动未仿真。

### 紧固件尺寸链与工具路径（审查补充）

每角 M3×30 内六角圆柱头螺钉，头包络直径 5.5、高 3；两枚 ID3.2/OD7/厚0.8垫圈；AF5.5/厚2.4螺母。必须采购不超过所列包络的实物。四个底部直径8、高3支承凸台补齐原底板角部，使下垫圈获得整圆承压面。螺柱通孔3.4。

从下到上：螺母 z=-3.2..-0.8，下垫圈 -0.8..0，底座及柱 0..20.5，上框 20.5..23，上垫圈23..23.8，螺钉头23.8..26.8。30 mm杆长自头下23.8至-6.2，穿过螺母后突出3 mm。顶/底垫圈各4枚，BOM垫片总数应为8。金属螺纹以光滑包络检查，未模拟螺纹啮合与扭矩。

装配时先从下方套入螺母及垫圈，用外径9、内空径6.6的薄壁套筒轴向托住；从顶部用直径4的工具包络旋紧。CAD验证套筒从z=-15到0、上工具从z=26.8到46.8不碰附件、M5或假设球。工具工作时不握底部，也不把产品放在桌面堵住路径。实际套筒端部结构、手柄及操作者手部尚需现场检查。预览包含硬件包络，不提供可打印螺钉。

该补充解决紧固件支承/几何验证缺口，不解决原球倒置保持。底部凸台使默认附件宽高边界变为约96×62×23 mm（不计硬件），完整含硬件高度约69.2 mm；体量与底部突出进一步说明其仅是附件实验。

## 装配顺序与验收

1. 用卡尺测原球三个方向外径及实体接触区。将实际外径传给脚本；超出 50–80 mm 不直接缩放 STL。
2. 先打印附件，检查 24.8×48.8 底托、通孔、框边、毛刺和层间强度。
3. 贴 2 mm 泡棉，放入 M5，确认不需挤压；装顶框，四角交替轻拧。顶框只限位，不压屏幕。
4. 裸露机身逐键按下、接 USB-C、拔插 Grove，确认插头有手指操作空间和线缆弯曲空间；不符合即修改，禁止硬塞。
5. 将原球置于掌托，逐层拨动，改变孔方向重复；对比拿出球的手感。如果被座压住，该球/姿态不通过。
6. 在软垫上试握持、携带带和倾斜；不通过保持力测试前不要倒置或口袋携带。连续把玩 10 分钟检查压手、疲劳和干涉。

以上实物步骤尚未执行。电子固件、耐久、跌落、RF、温升和电池续航未测试。

## 复现

```powershell
python -m pip install -r requirements.txt
python build.py --ball-diameter 60
```

在本目录运行；可用 `--output _checks/diameter50` 分离验证输出。导出代码断言每件网格闭合、单连通、正体积，并检查球、M5 和附件之间相交体积低于 0.01 mm³。原球模型不可访问，因此这些断言仅适用于指定包络，不是对源模型实物机构的验收。
