# 十日环 · 环轨式 Orbit-10

原创的中央电子仓＋捕获旋环。**当前为明日试打用数字制造样机，未实物打印。** 外径约75 mm，总厚30 mm，体量偏大，不称小巧。把底盘托在掌心，拇指/食指拨动外围十凹槽旋环；旋环被上下法兰永久捕获（拆螺钉才可卸下），M5StickS3 完整机身在中央可拆内托中。装好即可把玩，无需取出球或解开绑带。

所有塑件都是独立原创参数化几何；原 MakerWorld 仅代表旋转层次灵感，没有导入、描摹或复刻其几何。这里不需要原玩具尺寸。

## 明日最短试打路线

1. 先打4个校准件：普通PLA，0.4喷嘴，0.2层高，3壁，20%填充。环套在D12轴上，以不强压、能手转且晃动可接受为准。通孔从X负到正依次3.2/3.3/3.4，确认D3钢珠可自由滑过3.3孔，弹簧不卡孔。
2. 默认完整件采用径向单边0.5、轴向上下各0.4 mm。校准件不能代表整圆收缩，主环仍须干装。若0.5仍紧，先检查象脚、接缝及挤出校准，不能强压装配。
3. 功能件普通PLA先试，0.4喷嘴、0.2层高、4壁、5顶底层、25%填充。PETG可作更耐冲击备选，但拉丝和尺寸会改变，必须重打校准件。没有依赖打印弹性卡扣，避免PLA薄卡扣断裂。
4. 五件保持当前+Z朝上、底面放平。旋环下内缘有0.8×45°导入斜面。基座横向D3.3孔存在小跨桥，按切片检查；可用3.3钻头手动修孔，不能扩穿盲孔底。上框沉头朝上。内托压耳1.3mm级水平悬伸应查看切片，不直接启用全局支撑污染滑动面。
5. 不在旋环与导向圆柱间生成支撑（它们本来分件打印）。象脚补偿先用0.15mm作为起测，不作为实测校准结论。滑动圆柱接缝避开+X定位孔；轻去毛刺后干装，先无钢珠弹簧转一整圈。

## 装配（与拆卸）

1. 基座底面四个六角窝放入M3螺母，临时用可揭胶带托住，最终靠螺钉夹紧，不把胶带当结构件。
2. 光滑版跳过定位件。定位版从+X外圆孔先放弹簧，再放D3钢珠，用薄卡片压住；旋环下内斜面朝下，从上方滑入并抽出卡片。钢珠最终被旋环内壁捕获，不能向外飞出。勿把卡片留在运动副中。
3. 旋环落在下法兰上；先手转一圈确认无毛刺。放上捕获环，其异形内孔对齐内托位置。
4. 放入内托；四个外伸压耳压在捕获环上，使捕获环不能抬起。内托底坐在基座平台，螺孔对齐。
5. M5按正面+Z、USB/Grove朝+Y、HAT朝-Y放入内托。整机底z12、最高z27；没有硬压PCB或电池，机械旋转载荷走基座/法兰。
6. 上框放到立柱顶，四枚M3×30沉头螺钉交叉轻拧到底。螺钉头顶z30、尖端z0，不应突出底部。不要用电动工具或过拧压坏塑料。
7. 去掉临时胶带。确认上框、内托、捕获环均不能被手轻抬；旋环仍转动且上下不会脱出；M5正面和侧面键可触达。再接USB数据线，验证充电与串口识别。
8. 拆卸逆序执行，取下捕获环和旋环前用托盘接住可选钢珠和弹簧。电子件可单独拆出，日后只改内托/上框即可换设备。

螺钉尺寸链：顶面30→基座0，螺母z0.1..2.5，杆身z0..28.3，沉头z28.3..30。螺母有完整2.4mm长度与杆身重叠（螺纹啮合/扭矩未仿真）。四根立柱承受夹紧力，上框不靠压屏幕固定。上框内宽23，机身宽24，形成两侧各约0.5mm的实体防脱重叠；上框与机身最大包络间有0.5mm轴向余量。

## 运动与间隙

- 导向圆柱半径30；旋环内半径30.5、外半径37.5、高6。
- 旋环z3.4..9.4；下止挡z3，上止挡z9.8；轴向自由量总0.8。
- 上下法兰半径32.5，对旋环内孔径向覆盖2.0。装完后的旋环不能沿原装配轴向路径退出。
- 内托压耳锁住上捕获环，四枚螺钉锁住内托；捕获关系不依赖磁力、摩擦或绑带。
- 外圈十个凹槽是手指触点；内圈十个球窝配合可选钢珠压簧产生十段定位。钢珠在径向移动，旋环360°反复转动；原模型几何没有参与。
- 主间隙0.5径向、0.4每侧轴向是FDM试打假设，未经过本机补偿。可用`--radial-gap 0.35`或0.6重建并重跑验证，不直接整体缩放STL。
- 最薄内托低围边1.2；上框端横梁1.4；上捕获板2.2；上框厚2.5；立柱螺孔周围最小名义肉厚1.5；弹簧孔上下实体约1.75。局部沉头口为薄边，需清毛刺。接触边缘处理会在最终试打包完善。

## 验证与限制

`verification.json`包括9个零件的闭合/单连通/正体积、解析STEP回读、塑件配对相交、官方M5参考相交、插头与工具通路、硬件配对、全周每5°旋转，以及0/9/18/27/36°钢珠就位和压簧长度。上移/下移旋环0.5mm会与止挡相交，这是存在实体捕获的正向证据；装配名义位置不相交。尚未模拟结构变形、冲击、磨损、所有可能的倾斜逃逸路径、皮肤夹缝或电气工作。

未实打不等于已经验证手感。明日试打需检查：螺母窝与沉头实际配合、导向摩擦、定位强弱、全姿态保持、孔边手感、连续把玩10分钟、插头串口通信和实际携带。发现紧涩先拆开去毛刺/重调参数，不能靠暴力跑合。当前材料体积估算和75mm体量都应按真实掌中样机判断。

## 十日环语义（机械完整，电子映射待固件）

拨动旋环是“回到当前项目”的把玩仪式；十个段落对应十日节奏，但本版无旋转传感器，不能把旋转自动计作完成。M5屏幕显示十格，前键确认今日完成、侧键长按Seal、双击Grace；复位需组合确认。机械功能断电仍可用。十珠独立下沉在此版降级为十段旋转触感；固件不在本CAD交付中。

## 复现

Python3.12环境安装requirements.txt后：

```powershell
python build.py
python build.py --radial-gap 0.35 --output _checks/gap035
```

默认自动读取本目录`_reference/StickS3.stl`，也可`--reference 官方文件路径`。缺参考时报告会明确变成包络-only，不能替代本轮已记录的官方几何核对。`--skip-motion`仅供迭代排错，正式验收不得跳过全周运动。
