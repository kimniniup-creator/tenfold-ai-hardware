# 十日环｜针板式 EDC · M5 侧舱适配原型

**状态：已建模的独立配件，待原针板尺寸校准；不是完整复刻，也未实物打印。**

核心体验仍由 pearigee 的「大型手持针板解压玩具」提供：手指和掌面压动密集滑销，翻转后再压，形成连续触感。侧舱只承载 M5StickS3，不替代针阵、不封住针板背面、不把滑销改成屏幕按钮。原作品必须自行从作者页面合法取得，本目录不包含原针板或其衍生几何。

## 结构与机械保留

侧舱主体 64×40 mm，附 21 mm 安装翼；M5 位置为 X=8…56、Y=8…32、Z=3…18 mm。四角约束给名义单侧 0.5 mm 横向余量；盖框底面 Z=18.3 mm，前面名义间隙 0.3 mm。刚性托底顶面为 Z=2.5 mm，0.5 mm EVA 背垫占 Z=2.5…3.0 mm，M5 占 Z=3.0…18.0 mm；盖框底面 Z=18.3 mm，因此含背垫后的净间隙仍为 0.3 mm。**Z=3 已包含背垫，不能在这个坐标上再叠加一次0.5 mm。** 四角盖唇约束抬起方向，整机无需拆壳。

两组夹具位于 Y=9、31 mm，沿针板**静态外边框**固定。针板在 X≤-23 一侧，电子舱在 X≥0 一侧。夹具只伸入静态框 LAND mm，不得伸到滑销区。参数默认 `frame_thickness=8`、`frame_land=6` 是**工程校准样例**，不是原模型尺寸。当前 22 mm 夹具中心距、10 mm 夹具宽度也需结合真实外框/把手位置复核。

不使用整面背板、不在针阵下面堆电子件，保留压入、推出、翻转的机械自由度。加装后重心、握持和外缘可达性仍需实物评估。若原模型没有≥4 mm 宽且可夹持的静态边框，此夹持方案不成立，须依据实际把手设计替换连接件，不能夹滑销凑合。

## 文件与复现

- `build.py`：参数化 CadQuery 实体源，所有几何从尺寸和布尔运算生成。
- `exports/*.step`：四个独立零件和独立配件装配 STEP。
- `exports/*.stl`：四种打印件，底面已归零；上下夹具各打印两件。
- `exports/assembly.png`、`exploded.png`：真实 CAD 三角化装配及爆炸预览。橙色是 M5 标称包络，不是原针板或精细硬件复刻。
- `exports/validation.json`：网格闭合、包围盒、体积、实体相交检查。

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python build.py --frame-thickness 8 --frame-land 6
```

导出脚本会覆盖 `exports`；正式实测参数调整应先改 HANDOFF 记录再生成。脚本约束厚度4…14 mm、静态夹持宽4…10 mm，只表示此夹具的参数设计范围，不表示原针板适配范围。

## 装配与避让检查

1. 先确保原针板独立正常工作；测量外框厚度、可夹宽、直线可用长度、滑销正反面极限与把手轮廓。
2. 修改参数并导出。夹爪内侧铺0.5 mm软垫，下夹具位于安装翼下方；安装翼和下夹具间0.3 mm间隙用薄垫调平。螺栓依次穿过下夹具、安装翼、上夹具，下夹具底部和上夹具顶部各放一片垫片，螺栓从下方穿入、上方装螺母，均匀轻拧。两孔X=-17/-6 mm、中心距11 mm；使用符合BOM包络的工具从Z轴方向接近。
3. 放入带0.5 mm背垫的M5，装四角盖框和四枚螺钉；必须确认前面盖唇未压屏幕/按键，不能以拧紧强行消除尺寸不符。
4. 两长侧中央 X=12…52、短侧中央 Y=12…28 为主要开放窗口。USB-C插头、侧Reset、两个可编程键、Hat2、Grove必须逐一插拔/按压检查。几何上侧面大范围开放，但接口精确坐标和所用插头外壳未实测，**不宣称已经完成接口操作验证**。若某端口落在角柱遮挡区，调整柱位后重跑检查。
5. 对针板每枚滑销做全行程，正反翻转，检查夹具/螺栓/电缆未触及滑销；未取到原STL前此项为阻塞项。夹持后不应让外框变形压紧销钉。

## 下一道验收门

取得合法原STL → 本地测量边框和滑销行程 → 按实测参数重导出夹具 → 原件+夹具全行程干涉检查 → PETG试打印 → M5装机按键/USB检查 → 10分钟把玩及50次翻转 → 再决定是否进入黑客松演示。当前只能验收独立CAD与其名义包络检查，不能验收针板整机适配成功。

夹爪补充：上夹具在自由位置向下最多0.4 mm到达边缘硬限位，使两侧0.5 mm软垫总压缩量不超过0.4 mm；需实物确认垫材硬度和框受力。该行程已纳入脚本分段干涉检查，不能代替原针阵运动验证。

## 握持与未知整机体量试验（T-PIN-02）

见 `exports/grip-test.png`。图中只画已生成配件，左侧虚线表示原针板所在方向和未知范围，不是原针板轮廓。新版默认配件含M3紧固件约93×40×27.1 mm；原针板、M2.5螺钉头与电缆不计，**不能据此声称整机适合口袋**。

1. 先单独打印无电子配件，或做93×40×27.1 mm纸板体量块；用20 g配重近似M5重量。该试验仅筛查侧舱体量，不模拟原针板。
2. 合法原针板到位后测整机实际长宽厚、总重和重心；先在未夹持状态定位静态框与全部滑销工作区。没有合适静态框则停止装配，回到接口设计。
3. 两种握法分别试：A手掌托原针板背面、拇指扫针阵；B仅握原把手并翻转针板。夹具/侧舱不得成为强迫手指绕行、遮挡任一滑销或压到屏幕的支点。记录左右手能否操作、被挡销钉位置和照片。
4. 每种握法持续10分钟，并做50次翻转、20次全区域轻压。出现夹具移动>0.5 mm、销钉卡住、割手/明显疼痛或M5松脱即不通过；记录前后夹持位置，不用“感觉还行”替代结果。
5. 插入实际USB线再试10次翻转与放桌；确认电缆不进入滑销、工具夹持区，不把充电口当受力支点。
6. 用实测整机纸样/样件测试预定口袋开口和坐姿；无法舒适取放则将此方案定位为桌面针板，不宣称口袋EDC。当前上述实物测试均未执行。
