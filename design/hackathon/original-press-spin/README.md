# 十日环 · 原创旋压双舱

**明日试打包，未实物打印。主骨架/内托/转盘可用PLA；完整按压模式的按片与弹性卡销要求PETG。只有PLA时，选择PLA＋M3单旋模式，按压功能明确降级。** 这是一套原创机械EDC，不依赖MakerWorld。默认全打印旋压模式无需采购轴承或金属弹簧；另有更可靠的普通M3紧固替代。

机械玩法：左侧直径30mm转盘绕12mm打印滑动轴套自由旋转；右侧可换弹性片向下按1.4mm回弹。两种玩法断电可用。M5StickS3在抽屉内托中，屏幕朝下，翻面查看十日状态；旋转与按片没有传感器，不会自动假报数字事件。

## 文件入口与验证

- 源：`cad.py`；检查：`check.py`；Python3.12安装`requirements.txt`。
- 生成：`python cad.py`；检查：`python check.py`。
- `stl/`为已经定向且落到Z0的打印坐标；`step/`为装配坐标，`assembly.step`是全打印模式。
- `mesh_checks.json`记录闭合/法向/单实体；`mechanical_checks.json`记录旋转、按压、抽屉和插头通路。
- `assembly.png` / `exploded.png` / `underside.png` 为真实CAD装配、爆炸及底面图；`print_orientations.png` 为全部STL朝向。
- PrusaSlicer 2.9.6实际完成22件切片，全部退出0、非空挤出、无当前警告；`slicing_report.json`保留逐件证据。通用220×220配置仅做几何检查，不是你的打印机配置；未提供可直接上机G-code。
- 网格22件均闭合且为单实体；转盘全周包络、按压0–1.4mm、抽屉插入路径、USB/Grove插头包络及两套金属紧固静态装配均无CAD干涉。未实打，不等于可靠性认证。

## 材料与BOM选择

全打印旋压：body×1、m5_tray×1、wheel×1、bearing_sleeve×1、thrust_ring×1、rotor_pin×1、rotor_clip×1、press_leaf×1、press_pin_a×1、press_pin_b×1、drawer_key×1。按片、卡销、叉形卡簧和抽屉弹性销必须PETG。没有滚动轴承，12mm套筒是打印滑动轴承，不承诺长时间空转。无金属弹簧。

PLA＋M3单旋：body、m5_tray、wheel、bearing_sleeve、thrust_ring各1，加metal_rotor_cap、metal_rotor_sleeve、metal_rotor_lower_washer各1；替代rotor_pin/rotor_clip/drawer_key，省略按片与两卡销。外购：M3×16全牙低头螺钉1（头高≤2mm、头径≤5.7mm）、M3螺母1（高≤3、外接径≤6.4）、M3垫圈1（OD≤7、ID≥3.4、厚0.5）；M3×45全牙螺钉1、同规格螺母1、垫圈2用于抽屉横向锁定。普通高3mm的轴螺钉头不可替代低头，否则可能接近M5。

PLA刚件＋PETG按片＋M3完整旋压（减少弹性卡销依赖）：在上面的PLA单旋BOM上增加press_leaf×1（PETG）、M3×14全牙螺钉×2（头径≤6、头高≤3）、M3螺母×2（高≤3、外接径≤6.4）、M3垫圈×2（OD≤7、ID≥3.4、厚0.5）。螺钉从按片顶面穿入，下方垫圈和螺母夹住屋顶；先装机械再装M5。总计4颗螺钉、4颗螺母、5片金属垫圈。`step/hybrid_assembly.step`包含该装配和金属件占位；金属件不要打印。轻拧至按片根部不移动，不压碎层线，轴端螺母调到轮能自由转且无明显轴向晃动。未验证长期防松，首轮每次使用前检查。

可选：wheel_loose是12.7mm轴孔替代默认12.5；press_leaf_soft为1.0mm PETG片替代1.2mm，不同时安装。校准件cal_axis_holes、cal_axis_plug、cal_snap_sockets、cal_snap_pin、cal_m5_frame、cal_clip_open均不留在整机里。

## 打印朝向与材料

0.4mm喷嘴、0.2mm层高、4墙、25%填充作为切片起点。body已旋转90°，以+X端朝床，成形高64mm；需6mm brim与局部支撑，避开让整个M5舱屋顶成为长桥。端部短柱/按片安装台有短悬挑，支撑从开放底口和两侧窗取出，导轨接触面去毛刺后先空抽屉试滑。转轴套独立竖直打印，支撑不接触滑动轴面。

按片平放，无支撑，层线沿片面；轴销和卡销以大头着床；叉形卡簧和抽屉销平放。0.4mm止推片是两层，务必确认两层都切出；不得开启把薄件消掉的简化选项。最薄功能截面：软片1.0mm，默认片1.2mm，抽屉销弹性腿0.9mm，叉簧臂1.4mm。PETG烘干、具体温度以所用耗材与打印机为准。

## M5专用安装与数据口

仅针对官方K150整机48×24×15mm，不声称兼容其他板。包络X=-24..24、Y=-12..12、Z=4.8..19.8；屏幕朝-Z。官方图显示USB与Grove在同一端，安装时朝+X（固定后挡条一端）。此端中央预留14mm宽插头体通路，USB高6mm、Grove高7mm；电缆从+X插入。HAT端不保证原位全针排访问，需抽出内托。

内托只托外壳前面边缘，46×22mm窗口露出屏幕与正面键。body上方四个限位留0.6mm背面间隙，不将按压载荷顶在电子上。机械载荷经顶板/端柱到外框；没有FEA或实测载荷结论。官方结构数据来源：https://github.com/m5stack/M5_Hardware/tree/master/Products/K150_StickS3/Structures ，尺寸来源：https://docs.m5stack.com/en/core/StickS3 。官方STL仅本地检查，不随包再分发。

## 装配顺序与正向保持

1. 先打印轴孔和卡销校准件；校准不过不打整套。轴孔应能徒手旋转，不靠硬压；PETG卡销/卡簧应能弹性装拆3次无白化裂纹。材料/尺寸不合适改用M3模式。
2. 无M5时装机械：顶面放轴套、止推片、转盘，插轴销；从开放底口横向插叉簧至轴销槽。叉簧在窄槽内阻止轴销上拔，窄入口需扩张才能退出，不是靠重力放置。
3. PETG按片落在右锚台，两卡销向下压入孔，倒钩在顶板下展开；拆卸须从底口合拢卡销腿。按片极限落在两斜面硬止挡上。不要用PLA硬掰卡销。
4. 把完整M5放入内托，屏朝窗口；连同内托从-X端推到定位面，最后把横向锁销从侧面插入。锁销挡住抽屉前端，倒钩锁在外框外；先释放侧面倒钩才能抽出。M3版用横向螺钉、两垫圈和螺母替代。
5. 锁止后检查抽屉不能沿原路自由退出、轴销不能上拔、轮可转、按片可回弹、USB可插。暂未做这些实物测试。

机械运动几何测试不能代替材料弹性。按片的曲线为小挠度几何近似而非有限元结果；PETG蠕变、疲劳、摩擦、音感和口袋耐久均待试打。首轮仅作为桌面/手持原型，不做跌落保证。

## 明日试打SOP

1. 在自己的切片器选择真实打印机、喷嘴和耗材，导入已定向STL，保持100%毫米比例。优先选“PLA刚件＋PETG按片＋M3完整旋压”；若没有PETG，先试PLA单旋，不打印PLA按片冒充完整玩法。
2. 先打cal_axis_holes与cal_axis_plug：孔从X负到正依次12.3/12.5/12.7mm。默认12.5能自由转就用wheel；只有12.7能自由转则用wheel_loose；全部卡死先调孔补偿，不能硬压转盘。孔大到明显摇摆则停下调整，不靠增加螺母夹紧阻力补救。
3. 用cal_m5_frame检查真实外壳48.8×24.8窗口余量。它只检查平面尺寸，不能替代整机端口和托边试装。全打印模式再打印PETG cal_snap_pin、PLA cal_snap_sockets（8mm厚，孔从X负到正4.0/4.2/4.4）。正式孔4.2需能锁住且可释放，三次装拆无裂纹/明显白化；只有4.4可用时先改CAD正式孔并重新导出，不直接硬装。叉簧先与rotor_pin试配，可用cal_clip_open的4.6入口对照4.4默认入口。
4. 按所选BOM打印。body开启支撑、6mm brim；metal_rotor_sleeve开启3mm brim；其余默认无支撑。检查body内部屋顶、导轨、安装台支撑路径可从侧窗取出。移除所有支撑和brim，清除象脚；不磨薄弹性臂。0.4mm thrust_ring必须保留两层，另打备用片。
5. 不装电子先完成机械装配，手动旋转一圈、按压20次；轮不得磨壳，按片不得永久弯曲或越过止挡。再空托滑入滑出10次，最后装M5与横向锁定件。发现硬卡就停止修配，不能靠M5外壳承受装配挤压力。
6. 接USB，确认真实插头可插到底且设备被电脑识别；Grove使用实际插头核验。检查正面键、屏幕可访问。侧面键/Reset与HAT扩展不保证原位操作，必要时抽出。固件、数据采集和机械动作传感未由本机械包实现。
7. 首轮记录耗材、层高、孔补偿、轮间隙、按压手感和20次回弹结果；再决定疲劳试验。当前没有实物、摩擦测量、跌落或疲劳测试，不能称成品验证通过。

弹性装配预算：按片20mm有效力臂、1.2mm厚、1.4mm位移，小挠度估计表面应变约0.63%；按片卡销腿径向压缩约0.3mm，抽屉销末端每侧约0.15mm，叉簧入口每臂展开约0.2mm。这些只是几何/简化计算，不能保证层间强度、回弹寿命或装拆力。
