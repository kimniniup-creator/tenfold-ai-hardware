# 十日环｜原创十粒掌盘

**数字制造试打候选；未实物打印、未验证手感。** 完整原创EDC，不依赖原玩具，不复制任何MakerWorld受限几何。背面十枚独立圆头滑销可按入3.2mm、翻转/轻晃重力复位；正面容纳整机M5StickS3。无弹簧、无轴承、无磁铁，断电仍可把玩。不是逐日锁存机构，不宣称点击段落或自动识别单销。

## 首版范围与模型

默认本体70×42×29.2 mm；十销伸出时最大厚度32.4 mm。M5保持原壳48×24×15 mm，固定坐标X=11…59、Y=9…33、Z=11.7…26.7。承力隔板顶Z=10，内托1.2mm+EVA总厚0.5mm，前压条底Z=27，含软垫净余量0.3mm。

- `build.py`：原创参数化CadQuery；`exports/*.stl`已转换到打印方向并归零，**直接导入切片，不再旋转**。
- STEP单件保留装配坐标；`assembly_printed.step`为16个打印实体，`assembly_hardware.step`另含16个紧固件包络。
- 参数`--shaft-gap .2/.3/.4`表示单边径向间隙。默认.3，先打校准件再决定。
- 电子内托独立可换；板长/宽/高有参数，但**首版验收仅M5默认48/24/15**。其他板需重验端口、固定、压条和线束，不能只缩包络便声称兼容。

## 装配

1. 先完成校准：同材料/朝向打印销、导孔条和腔体试片。孔条左到右为径向.2/.3/.4。去象脚和毛刺后，将销从内侧插入导孔，大法兰留在内侧；套上5.2mm腔体，用打印的calibration_roof临时盖住腔体，手持夹紧。检查3.2mm全行程，连续50次按入/翻转无卡死；轻晃可复位、销不可穿出导孔。不满足则选择更大间隙并重新生成，不能强拧电子件掩盖卡滞。
2. 导向板朝下放在两条≥4mm高支垫上，十销从内侧逐一插入，法兰留在上方；盖限位夹层，再盖承力骨架。不要翻转未固定的夹层。
3. 把四枚螺母从短柱顶部放入对应5.8mm六角槽到底；从背面上四枚M3×16，分次对角轻拧。销应仍可自由运动，若拧紧后卡住即停止并检查平面/象脚。
4. 四枚前压条螺母从四角高柱顶落入至Z=10平台；可用细杆辅助对正。放独立内托对准两定位柱，贴总厚0.5mm背垫，放M5。USB/Grove朝+X，HAT朝-X，屏幕朝+Z。
5. 两条前压条分别装在Y低/高侧，一条相对另一条绕Z转180°；四枚M3×25由正面拧入。确认屏幕/前键无受压、M5无脱出、端口可插。
6. 正反面全行程按动，桌面与左右手各试10分钟；记录卡销、夹皮肤、尖角、螺钉松动、USB线受力。未通过不进入随身使用。

## 接口与玩法

[官方M5规格](https://docs.m5stack.com/en/core/StickS3)、[尺寸图](https://m5stack-doc.oss-cn-shenzhen.aliyuncs.com/1207/K150-sticks3.pdf)、[官方结构文件](https://github.com/m5stack/M5_Hardware/tree/master/Products/K150_StickS3/Structures)已核对。官方STL含散放重复件，整组138mm跨度不是整机长度；只有装配组用于包络核对，原文件不再分发。

官方坐标长轴Y旋转到本设计X：高Y的USB/Grove→+X，低Y的HAT→-X，前屏/前键→+Z。两端中央完全敞开，脚本检查16×16mm端面数据插头直入通路；大壳/直角线仍需实配。正面前键与屏幕处于两压条之间；侧面可编程键、Reset要在装机时逐项按压，不能拿通道检查替代真实按键测试。

针阵用于真实反复按压/扫过和翻转复位。电子按键、屏幕状态和十日流程以项目[USER_JOURNEY](../../../docs/hackathon/product/USER_JOURNEY.md)及软件任务最终固件定义为准，本硬件包不指定Seal/Grace等业务键。机械针阵仅用于把玩，随机压针不应自动计完成；本包不包含已实现固件。

## 官方结构与独立验证

`verify_m5_reference.py --reference 本地StickS3.stl` 可复现本包的官方参考检查，第三方STL不随仓库分发。脚本取官方3个装配位置壳体，作正交旋转（官方+Y→本设计+X、官方+X→本设计-Y、+Z不变），验证全部顶点/三角形落在比标称包络每边大0.01mm的凸长方体内，再对32个打印/五金实体逐一做该保守包络的CSG相交。见`exports/m5_reference_validation.json`。这是保守包含性证明，不冒称直接网格布尔或真实装机。

独立测试的首候选证据：[b4ba300 官方M5参考报告](https://github.com/kimniniup-creator/tenfold-ai-hardware/blob/b4ba300/docs/hackathon/testing/original/pin-81c0682-m5-reference.json)，实际官方三壳与32实体相交最大值0；九种STL已做无支撑切片。其O-PIN-01发现内托定位耳孔外仅0.25mm，本版已把外缘延至Y=3/39，保留孔位后最小外唇1.25mm，重新跑全套装配/运动/通路检查。侧键仅有官方结构与开放侧边观察，未做实机手指按压测试。
