# 产品判断与黑客松验证

证据编号对应 [EVIDENCE.md](EVIDENCE.md)。以下为产品建议与待验证假设，不是论文已经验证的M5结论。

## EDC优先：先证明愿意带、顺手玩、不打扰

我想先验证它能否成为人自然带在身边、工作间隙会拿起来的物件。P9–P11把重复动作、个人意义、情境与技术取舍放到前面；这比先做压力推断更贴近日常使用。研究EDC不意味着恢复已冻结的机械外壳设计。

1. **低注意力把玩**：单手、不看屏幕也能自由按，宠物偶尔可看而非每次索取注视。依据是P9的旁路交互构想与P11的任务依赖观察；M5是否真能盲操作仍须实测。
2. **电子反馈必须挣得它的位置**：与用户本来会玩的笔、戒指、硬币等作比较，避免只比较两种电子动画。P10里技术物件是少数，不表示技术无价值，但说明不能默认加功能就更好。
3. **个人偏好不是情绪诊断**：记录用户喜欢的节律、安静程度、宠物外观与互动方式；不要用某种触感偏好分类心理状态。P10自定义与依恋是相关证据。
4. **公共使用需要隐私和克制**：声音默认可关闭、不主动播报情绪、不反复亮屏；同时观察旁人能否接受。P9/P10提供设计动机，不提供本机噪声或社交接受度验收。
5. **真实手感单列门槛**：拇指疲劳、边缘压手、按键位置、误长按、携带误触、按键寿命、单手取放都未被论文或本轮研究实测。软件宠物不能补偿不舒服的按钮；耐久不得用几分钟试用声称通过。

### EDC验证先于降压实验

- 黑客松先做6–8人、每人10–15分钟的原生按键探索：惯用/非惯用手、看/不看屏幕、读短文/听内容/简单打字三种主任务；只在安全静止环境，不要求通勤行走操作。记录误触、握姿改变、抬眼次数、主任务错漏、手部不适以及是否愿意带走。此样本量只是可用性探索。
- 对照至少包含无物件、用户已有熟悉小物、M5最低确认、M5宠物响应；过多条件时分两轮，随机平衡顺序并匹配任务难度。喜欢与记忆/工作表现分别记录，避免“更好玩”遮蔽分心成本。
- 可行性通过后做3–7天随身日记：实际带了几天、放在哪、何时拿出/收回、为何没带、是否只因研究要求使用、声光是否尴尬、是否想关闭Agent。每天最多一次简短回顾，事件记录自愿，设备无点击不能推定没携带。
- 主要判断先用自然携带/使用、舒适、主任务打扰、可关闭性；当下紧张前后变化为独立探索指标。没有显著降压仍可能是好EDC；持续抢注意也不能因短时喜欢就判成功。
- 原型通过后再做下面更聚焦的A/B情绪体验实验。当前没有完成以上试验，所有手感/耐久/携带结论均待验证。

## 如何处理情绪

我倾向先让用户决定需要什么，再用互动摘要调整回应。按钮负责表达操作和把玩，宠物负责回应；不要求用户先被系统判断成焦虑才获得陪伴。

| 输入层次 | 允许说什么 | 不允许跨越的推断 |
|---|---|---|
| 原始事件 | 有效按下/松开时间、次数、持续时间 | 没有传感器就没有力度、心率或皮电 |
| 行为摘要 | 每分钟次数、间隔中位数/IQR、按住时长、会话长度 | 次数增加不代表压力增加 |
| 个人基线 | 同一人、相似使用模式下比平时快/慢 | 基线偏离不是情绪标签，也不是诊断 |
| 用户自报 | 用户此刻说紧张、无聊、开心，或不想回答 | 自报不是客观生理真值，且可随时纠正 |
| 统计估计 | 仅在独立验证后报告误差及不确定性 | 不输出未经验证的0–100焦虑分数 |

P1说明时序值得研究，但其标签是SAM效价/唤醒。高唤醒可能是开心、兴奋、忙碌或紧张；效价、唤醒、压力、状态焦虑与临床障碍不是同一变量。单按钮还受到新奇把玩、节拍游戏、任务难度、手部疲劳、姿势、习惯、长按菜单、误触、消抖、漏包和固件采样影响。闲置只意味着没有记录到按键。

个人基线应按自由把玩/导航/引导模式分开，记录有效观察时长，样本不足返回unknown；统计阈值只能表示行为离群，不能改名情绪置信度。若未来训练模型，标签与点击窗口对齐、按人和时间划分训练测试，避免同一人的相邻窗口泄漏；同时报告跨人留出与个体校准结果、MAE或平衡准确率、校准与拒答率、混杂和亚组差异。不能直接套论文准确率。

## 测量时间窗

| 工具 | 所测内容与时间窗 | 本轮用法 |
|---|---|---|
| 当下0–10自报 | 此刻紧张/平静，单题自定义体验指标 | 可选前后测，明确非诊断、非已验证焦虑评分 |
| SAM | 当下效价/唤醒；P1用9点版 | 理解情绪维度，正式使用核对版本 |
| STAI状态分量表 | 当前状态；P3短版用于各时点 | 如正式研究使用，核对中文版效度与授权 |
| GAD-7 | 过去两周症状频率 | 不作每秒或每次点击标签 |
| PSS-10 | 过去一个月感知压力 | 不作短会话前后效果指标 |
| HRV/EDA | 生理信号，受测量环境和多因素影响 | 当前无传感器，不生成、不估装成实测 |

量表窗口核对：[CAMH GAD-7官方医疗机构表单](https://www.camh.ca/-/media/files/gad-7_english-pdf.pdf)、[Cohen实验室PSS-10](https://www.cmu.edu/dietrich/psychology/stress-immunity-disease-lab/scales/html/pss.html)。[实验室说明](https://www.cmu.edu/dietrich/psychology/stress-immunity-disease-lab/scales/index.html)亦强调PSS不是诊断工具。修改问题时间窗后不能沿用原量表的效度主张。

## 各种反馈的证据边界

| 反馈 | 能支持的产品假设 | 不能说的结论 |
|---|---|---|
| 原生机械点击 | 可能有节律把玩与控制感；本机待测 | 点击本身已被证实即时降压 |
| 即时像素/声光响应 | 反馈可理解性、喜欢、参与度应单独测 | 响应快/用户喜欢就证明压力下降 |
| 振动或起伏触觉 | P3/P8提示特定实体反馈值得研究 | 当前板载已有该能力；振动等于点击 |
| 可选呼吸引导 | P4/P5支持研究，P6要求主动对照 | 某固定频率对所有人最好；30秒已临床验证 |
| 生物反馈 | P7提供间接参考 | 无生理传感器的动画也能做HRV反馈 |
| fidgeting | P2要求保留阴性可能和人群差异 | fidget必然有效，或因P2就断言M5无效 |
| 像素宠物 | 可测试陪伴、注意转移与可接受性 | P8证明像素宠物治疗焦虑 |

## Agent最小决策流程

1. 用户主动开玩；每个有效输入有简短可预测的本地回应，不必每次调用Agent。
2. 聚合会话摘要，只传必要统计、当前模式、明确偏好与可选自报；保留source和时间。默认不上传原始逐键日志。
3. 无自报或用户选择“只玩”时，只描述互动或安静陪伴。不得由连点推断“你压力很大”。
4. 明确自报紧张且允许建议时，给一次可跳过选项：“想继续玩，还是跟着慢慢呼吸一会儿？”普通连点不触发反复情绪询问。
5. 呼吸模式为可退出的舒适节奏，允许调整，不强迫深吸、屏息或过度换气；不适立即结束。停止/静音优先于所有动画与奖励。
6. 结束后可选一次“现在比刚才更平静、差不多、还是更不舒服？”跳过不扣分；不把未回答解释成情绪恢复。

可用不确定性措辞：“刚才点得比这次前半段快了一些；这也可能只是玩法变了。”默认更简洁：“我在，要继续玩一会儿吗？”不展示伪精确“焦虑概率82%”。宠物不因用户离开衰弱、不因连点痛苦、不把安抚宠物当用户义务；P8报告的内疚与感官负担使这些成为需检验的设计约束。

## 最小有对照实验（建议，不是已完成）

先测反馈额外贡献，不在同一次小样本里同时证明识别、呼吸和陪伴疗效。

- **问题**：同样M5按键使用，响应式宠物相比最低输入确认，是否更受欢迎、是否改变短时主观紧张？
- **可行性样本**：12–20名自愿成人，明确只是探索性试验；无临床筛选、无故意高强度诱发焦虑。小样本不能证明临床有效。
- **交叉两条件**：A只有中性输入确认；B相同亮度、相同按钮和时长，加入响应式宠物。各3分钟、AB/BA随机平衡，中间至少2分钟自然休息并记录恢复；有残留就延长/另日，不假设洗脱一定成功。自由点击，不强制次数相同，次数是结果之一。研究说明两者都是界面方案，不暗示哪个能减压。
- **主要终点**：预先确定“当前紧张0–10”的前后变化差，差中差=(B后−B前)−(A后−A前)。这是体验指标，不是焦虑诊断。喜欢、控制感、分心/烦躁、退出率与点击量列次要指标，分开报告。
- **分析**：以人为单位展示配对差和95%CI（配对bootstrap可作探索，说明小样本不稳定），保留所有退出/缺失并报原因；不能把几千次点击当几千名受试者。记录顺序效应、测试前偏好和期待，零结果照报。不能仅凭B内部前后显著而A不显著就宣称B优于A。
- **成功条件**：流程可完成、反馈可理解、愿意再用、无明显强迫/负担，是原型接受度目标；紧张变化不确定就如实保留。喜欢提升但紧张不变仍可支持玩具价值，不升级为减压疗效。

另开呼吸实验时，比较同样宠物与同样时长下的舒适呼吸引导/匹配注意的安静动画；记录期望与实际执行，不能把所有改善归因节律。另开输入估计研究时，在自然多次使用中收集少量对齐自报和场景，先检验个人内关系与基线模型，数据不足不训练“情绪AI”。

## 宣称清单

可说：“原生按键把玩与像素回应”“根据你选择的偏好调整陪伴”“提供自选节奏暂停”“正在验证它是否让短时体验更轻松”。若试验完成，只按真实结果说具体样本、条件、指标与不确定性。

不可说：“AI读懂焦虑”“点击多说明压力高”“按一下即时降压”“测得HRV/皮电/力度”“经过临床验证”“降低焦虑X%”“替代治疗”。没有传感器、验证集、对照和合适时间窗，就不能补这些结论。
