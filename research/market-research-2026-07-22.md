# Tenfold 十日环｜市场、竞品、制造与中国合规事实核验

**研究日期：** 2026-07-22
**研究角色：** R3 独立事实核验（非立项结论）
**来源规则：** 仅采用市场研究机构官网、厂商官网/支持页、政府/标准组织官网。未找到一手来源的数字不纳入。所有未注明发布日期的动态产品页均记录访问日期。

## 一页结论

1. **可穿戴是大市场，但大盘不能当 Tenfold 的 TAM。** IDC 的 2026Q1 全球可穿戴出货 1.457 亿台包含耳戴设备，后者约占三分之二；与 Tenfold 更接近的腕戴、智能戒指和行为干预设备都小得多。
2. **智能戒指在增长，但它验证的是“无屏健康传感”而不是“十日周期实体锚点”。** IDC 预计 2026 年智能戒指出货 490 万台；Omdia 曾预计 2025 年略超 400 万台，两家方法和分类不同，不宜串成连续时间序列。
3. **直接替代尚未被证明为空白。** Pavlok 是行为改变可穿戴；TIMEFLIP2 是实体交互+App 的生产力硬件；Beeminder 是承诺装置。Oura/WHOOP 属于健康/恢复型间接替代。当前检索没有发现“300 天目标切成十日周期、减法物理进度、24 小时恢复”完全同构产品，但这不等于完成了专利、众筹、淘宝/小红书或区域长尾产品检索。
4. **厂商周期只能支持工程假设，不能支持 Tenfold 的交付承诺。** Seeed 的“最快 7 个工作日”针对生产资料已完成且使用在库料的 PCBA；外观、结构、固件、调试、返板、认证和物流均不在这个数字内。当前没有供应商报价，因此不应在 deck 写正式 BOM、模具费或量产交期。
5. **中国首发至少要预留射频、锂电、Bluetooth SIG、App 备案、PIPL/数据出境与中国 RoHS 工作流。** 具体是否适用必须在射频方案、供电方式、App/云架构和产品分类确定后，由认证实验室与法务确认。

### 2.2 可以与不能说的竞争结论

**可以说：**

- 市场已验证三类付费方式：高价硬件+小额订阅（Oura）、订阅内含硬件（WHOOP）、一次性行为设备（Pavlok/TIMEFLIP2）。
- 与 Tenfold 最接近的现有价值不是“AI 穿戴”，而是 **Pavlok 的行为干预、TIMEFLIP2 的实体交互、Beeminder 的承诺机制** 三者交集。
- 健康穿戴的售价说明用户会为“持续可感知的洞察”付高价；并不说明用户会为长期目标进度支付同等价格。

**不能说：**

- “全球没有竞品”或“首个十日进度硬件”。当前没有完成专利库、众筹平台、中国电商、独立站和非英文市场的系统性检索。
- “Oura/WHOOP 用户就是 Tenfold 用户”。它们主要服务健康、睡眠与运动表现。
- “智能戒指市场 490 万台，所以 Tenfold 可卖 X 万台”。形态市场不等于任务市场。
- “Pavlok 售价证明 Tenfold 可卖 $184.99/¥999”。价格必须经过支付意愿实验与真实 COGS 反推。

### 3.2 当前 deck 应怎样写

**建议写：**

- “被动物件实验：无需电子与模具。”
- “电子 EVT：现成模组/开发板 + 3D 打印或软材料外壳，板级迭代按周估算。”
- “量产周期、模具费与认证周期：待 ID、射频、供电和生产资料冻结后由实验室/供应商报价。”

**禁止写成既定事实：**

- ¥260 BOM、¥299–499 零售价、X 周量产、X 万模具费。
- “7 天做出产品”或“2 周完成硬件”。7 天仅可能覆盖满足特定前提的一轮 PCBA。
- 未经报价的良率、返修率、电池寿命、防水等级与交付时间。

### 3.3 报价前必须冻结的输入

1. 形态与佩戴位置：戒指 / 腕带 / 夹扣 / 桌面件。
2. 是否带电、是否带显示、BLE/NFC 是主动还是被动。
3. 电池类型、容量、充电方式和目标续航。
4. 触觉/灯光/按键/可拆珠的状态机与耐久要求。
5. App、云端和 AI 是否是首版必需。
6. 试产数量、目标良率、测试工序、包装和首发地区。

## 4. 中国首发：BLE/NFC、锂电、App 与隐私的高层框架

### 4.3 认证/合规决策顺序

1. 先选形态与最小功能：**被动 NFC / BLE / 无线都不要**不是同一条认证路线。
2. 冻结射频、天线、电池与充电方案后，向具备资质的实验室做预评估。
3. 同步冻结数据流：设备 → 手机 → 中国云/境外云 → LLM/分析商。
4. 再形成正式测试矩阵、样机数量、费用与周期；这些在实验室确认前不得写成已知数。

## 6. 卡点与下一步研究

### 已卡住、不得在 deck 写成事实

- Tenfold 的 SAM/SOM、首年销量、CAC、复购与订阅率：无一手用户/渠道证据。
- BOM、模具、认证费、测试样机数、良率、交期：没有冻结规格和正式报价。
- “全球首创/无直接竞品”：未完成专利、众筹和中国长尾市场检索。
- BLE/NFC 最终合规路径：射频、天线、模块与产品类别未冻结。
- 健康/医疗属性：当前概念不应主动进入该范围；若加入生理传感、诊断或治疗主张，需另开法规评估。

### 建议下一动作（均不需要外联即可先完成）

1. 把 deck 市场页拆成“全部可穿戴背景 / 相邻形态 / 真实任务市场待验证”三层。
2. 将竞品轴改为：**行为干预强度 × 进度可见性**，把 Pavlok、TIMEFLIP2、Beeminder 放在主图，Oura/WHOOP 放价格/佩戴参照。
3. 为阶段二物件实验固定一个无电子版本，以免过早承受 BLE、锂电和 App 合规成本。
4. 阶段三前完成：产品规格 v0.1、数据流图、实验室问询清单、供应商 RFQ 包；外联时再请求 action-time 授权。
