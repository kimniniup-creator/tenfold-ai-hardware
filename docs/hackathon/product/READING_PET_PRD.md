## 核心场景

阅读时把M5拿在手边：随意按压与宠物互动，想留记号时主动标注，再继续读。宠物随真实互动积累成长。屏幕为135×240竖屏，沿用美术任务中Kim最新形象要求；不回退旧横屏角色。

成长反馈是否有价值仍需体验验证。互动次数只表示玩过，不代表阅读页数、读完、专注时长或压力。既有注意力研究为设计依据，不是效果证明。

## 首版需求与验收

| 项目 | 规则 | 验收 |
|---|---|---|
| 本地把玩 | 中央通用键自由点击，即时按压/回弹，不逐次弹文案、不等待Agent | 连按有反馈，长按只算一次按下；放下无惩罚 |
| 成长 | 至少幼年/成长两个可辨阶段，按真实有效互动积累；适度批量持久化 | 重启保留已保存成长，不逐按写flash；阈值与保存边界由软件公开固定 |
| 阅读标记 | 用户主动记录当前阅读会话的一个标记，有明确成功/失败反馈 | 不知道书名/页码时只保存会话打点，不声称能恢复纸书准确位置；保存失败不显示成功 |
| 模式 | 阅读首先完整可用；工作/健身/学习可作简单模式入口 | 模式名不冒充独立的训练/学习能力；切模式不误记标注 |
| 竖屏 | 135×240，新形象，短自然中文，文字不遮宠物/截断 | 预览、编译与实板显示分别验收；“按摩”是交互比喻，不宣称振动或力度感知 |
| 离线 | 把玩、已保存成长和本地标记不依赖模型 | 断USB在电池供电下真实验证，重连不重复记数 |
| Agent | 不作为本地把玩/成长/标记前置；具体材料理解与建议仍未选定 | 不自动把连按解释为走神，不将旧五句陪伴改名为阅读理解 |

种菜是后续玩法候选，首版不实现完整农场。宠物不因用户离开生病、死亡或责备，不把快速刷点击设计成阅读成绩。

## 实体键约束

Kim希望中央互动、左侧标注、右侧换模式。官方StickS3资料只有KEY1/KEY2两个通用键，另一侧键为电源/复位/下载键，不能直接映射为第三业务键。软件需核实实板位置；当前工程候选为A互动、B短按标记/B长按切模式，松开后判定且长按不先产生标记。提示文字必须与实板一致。此处记录工程候选，不宣称三键可用已实测。
