# M5像素陪伴搭子 · 两天黑客松PRD

2026-09-22，Kim已明确选择并授权开发。此文取代十日任务/封存恢复作为本轮产品目标；旧发布保留历史，不延续外壳、训练计组、任务日志需求。

## 产品与使用场景

M5Stick本机就是EDC：空闲时按原生按键，原创像素小角色即时回应；按压节奏是Agent了解互动方式的上下文，偶尔提供简短陪伴。屏幕参照老式电子宠物的低分辨率风格，角色和资产原创。无需额外外壳、手机录入、每日任务或养成惩罚。

占屏指M5本机屏幕；电脑是可选USB Agent桥接，不要求桌面抢焦点或手机悬浮权限。按压频次不构成情绪、生理或疾病判断；“舒压/疗愈”是体验意图而非医疗疗效承诺。

## 两天可交付闭环

上电看见小角色 → A按键立即反馈 → 本地汇总节奏 → 可连接电脑Agent → 屏幕一句轻回应/动画 → B选择陪伴或安静 → 断网继续本地玩。

| 编号 | 需求与边界 | 验收 |
|---|---|---|
| P01 | 原生A每次有效按下立即触发压扁/跳动/表情等动画；无需网络 | 连按仍流畅，长按只记一次有效按下，不把按住时长当连击 |
| P02 | B短按切换轻陪伴/安静状态；界面明确可退出，安静时不自动发起Agent提示 | 按B立即变更状态；过时网络回复不能把安静状态覆盖 |
| P03 | 汇总最近窗口有效按压次数、间隔/持续时间和模式；会话标识及窗口序号去重 | 摘要可与已知按键输入核对；计数/时间溢出有边界；不做焦虑评分 |
| P04 | 动画与按键在设备本地执行，USB/请求延迟不能阻塞主循环 | 断线/超时仍能玩；有可辨认的本地/Agent来源状态，勿大段技术日志占主界面 |
| P05 | Agent只接收小摘要和明确偏好；选择已审短句（ID或原文严格匹配）和受限动作，不生成任意文案或命令代码 | 输入输出限长；未知短句/ID/动作、畸形JSON、总时限超时走本地fallback；密钥只在主机环境配置，不进固件或Git。Agent来源表示模型选择，规则选择标本地 |
| P06 | 回应克制：连续互动达到阈值才候选；自动提示默认至少60秒冷却，一次至多一条 | 高频按压不导致逐次模型调用；重连不重播旧消息；静置不催促 |
| P07 | 原创像素宠物至少idle/blink/press/happy/rest；屏幕文字不截断、短句居次 | 实际分辨率适配；提供屏幕渲染/实板证据；不因未互动饥饿死亡或责备 |
| P08 | 不联网仍完整可玩；有密钥才启用真实LLM，无密钥明确本地规则 | 实测离线及真实Agent分别记证据，不用规则冒充LLM |
| P09 | 保存适量偏好，不逐次写闪存；旧固件升级前备份，标识正确板型 | 重启可用、旧固件恢复路径留存；不无故全擦flash |
| P10 | 交付新固件、主机bridge运行入口、PRD、美术资产、测试与演示说明 | 源码commit/push、可编译可烧录；板上输入/像素反馈/bridge三层证据独立标记 |

具体摘要窗口和节奏阈值由软件在协议中定值并向测试同步。不把高频自动等同负面情绪。示例回应：“我在，陪你待会儿。”“要不要慢一点玩？”不能说“检测到焦虑”“你今天不够努力”。无回复也允许角色安静陪伴。

## 实现与协作

M5StickS3+M5Unified；准确芯片/屏幕参数由实板识别。USB电脑桥接作为首条Agent链路，手机APK不是前置。现有物理按键本身手感需用户真实按压反馈，动画不能证明舒压效果。无原生振动能力则不宣称振动反馈。

产品任务负责需求、整合和串口租约；原软件任务负责固件/bridge及唯一烧录；新美术任务负责design/pixel-companion与pet_assets.h；原独测任务负责测试；原验收任务独立复核。每人独立worktree，只写自己范围。软件与美术直接对齐数组接口。串口一次一个owner。

## 演示与完成边界

30–60秒现场演示：显示待机宠物，真实按A看到立即反应；查看一条摘要进入bridge；真实Agent或明确本地规则回应上屏；B进入安静；断USB继续玩。屏幕截图或协议注入不能冒充物理按键实测，真实LLM未接通时明确列缺口。

本轮不做健康诊断、训练识别、完整聊天、多宠物经济、账号系统、社交排行、桌面占屏、手机常驻悬浮、定制外壳。收到新的明确需求再调整，不暗中扩展。
