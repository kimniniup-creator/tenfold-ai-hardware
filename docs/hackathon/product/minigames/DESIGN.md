# 阅读宠物：五款两键小游戏实现设计

2026-09-22 · 设计提案 v1 · 尚未实现、未烧录、未实板试玩。

本稿供协调 owner 派给既有固件 owner 实施。沿用现有黑白塔奇克马同人宠物，不新增角色 IP。权威成长规则为 [TASK_GROWTH_CONTRACT](../TASK_GROWTH_CONTRACT.md)。源码读取基线为 `9b055f0`，其固件仍含旧互动成长；本设计必须在任务成长契约实现之后接入，绝不从旧 interactions 推导解锁。

## 1. 目标与取舍

在用户主动休息时，给宠物一个“和我一起做事”的短场景。每局30–60秒，无排行榜、积分商店、连胜奖励、每日奖励或失败惩罚。局末默认回书，既不自动续局，也不倒计时催再玩。

| 顺序 | 游戏 | 玩家 / 宠物关系 | 核心输入 | 建议局长 | 实现复杂度（相对） |
|---|---|---|---|---|---|
| 1 | 一起跳绳 | 玩家摇绳，宠物跳；二阶互换 | A按节拍 / B提前示意慢拍 | 36秒 | 低：周期时钟与单窗口 |
| 2 | 羽毛球对打 | 玩家下场球拍，宠物上场对手 | A左接 / B右接 | 40秒 | 中高：轨迹、AI、碰撞窗口 |
| 3 | 敲敲回声 | 宠物出两键节奏，玩家回应 | 看完后A左 / B右 | 40秒 | 低中：序列与回放 |
| 4 | 接住书签 | 宠物上方递书签，玩家下方接 | A左 / B右，选定后等落下 | 36秒 | 低：离散两轨时序 |
| 5 | 一起修桥 | 玩家排桥，宠物逐段试走 | A换朝向 / B确认 | 48秒 | 中：固定关卡与局部连通 |

先做跳绳验证共用入口、输入消费和返回，再做羽毛球验证双方反应。其余按回声→书签→修桥。书签成本低但与羽毛球两轨反应相近，放后；修桥提供真正不同的规划玩法，成本最高。工期须由现有固件 owner 评估，本表不是工时承诺。

## 2. 成长与娱乐完全分账

| 能力 | 一阶 young | 二阶 grown | 解锁来源 |
|---|---|---|---|
| 跳绳 | 玩家摇绳、宠物跳 | 新增“换你跳”：宠物摇绳、玩家A跳/B蹲过高绳 | 已保存 growth_stage |
| 羽毛球 | 固定中速对打 | 新增选路回球：接到后A左/B右发回，对手按确定规则追球 | 同上 |
| 回声 | 2拍、3拍序列 | 新增轮流作曲：玩家2拍，宠物复述并加1拍，玩家复述3拍 | 同上 |
| 接书签 | 固定两条直落轨道 | 保留相同玩法；不冒充新增能力 | 无新增 |
| 修桥 | 菜单灰显“成长后一起修桥” | 开放完整修桥 | 已保存 growth_stage |
| 最近标记回看 | 契约锁定 | 原契约真实功能保留 | 任务节点，不受游戏影响 |

菜单读 stage 只读快照；每局固定 entryStage，不在中途改变难度。游戏期间收到合法节点确认由原任务模块正常保存/ACK，成长展示排队到回主页，下一局才获得新机制。退出/重启不回退已保存成长。游戏不可调用 node_complete、写 completed_nodes、伪造阅读标记、更新喂饭/清理、改变饱食或死亡状态；旧互动统计如保留必须区分来源，游戏输入不得进入“阅读互动摘要”。

首版不存分数、不存连胜，仅RAM里显示本局结果。无成长货币、经验条或娱乐换任务节点。重复玩1000局仍不能成长。未来若要保存最喜欢游戏，另立独立 schema，不能挤占64条节点去重表。

## 3. 入口、退出与两键仲裁（集成必做）

主页单键保持原契约：A短照料、A长≥700ms二阶回看；B短标记、B长≥700ms换模式。提出新增**主页双键重叠按住700ms打开菜单**，不改变单键阈值。实物两键能否舒适同时按待手持实测；若不舒适，由owner另审入口，不擅自把B长改菜单。

仲裁必须先于旧 ReadingInput，而不是在旧输入处理之后补检测：

1. 单键按下只允许即时视觉按压；业务提交等松开。任一时间出现A/B同时按住，即进入 CHORD，清空双方单键候选，记录双键重叠起点。
2. 连续双键重叠≥700ms，进入 MENU_PENDING_RELEASE；全部松开才显示菜单并接受新输入。短于700ms的重叠也消费双方本轮按压，不补发照料/标记/长按。第二键晚到亦按重叠起点计时，不借用先按键的时长。
3. CHORD后直到两键全松开都不恢复单键派发。轮询须处理“同一帧一键释放另一键按下”的边缘：只有采样到实际同时按住才构成和弦；从未重叠则保留两个独立单键语义。
4. 阈值用无符号时间差处理 millis 回绕；去抖20ms，阈值计时从去抖后的状态边缘起。699/700ms基于逻辑输入时间测试；实板机械抖动另验。

菜单每页3项，A短按下一项并循环，B短按选择，B长≥700ms直接回主页，A长不动作。第一项“回到书里”，再列5游戏；锁定项B仅显示锁定提示1秒，不进游戏。菜单15秒无输入回主页。主页底栏增加静态小提示“两键长按 游戏”，不能主动弹出邀请或定时推送。

选择游戏进入 RULES：至多两行操作说明，A短开始、B任意松开取消；5秒无操作回菜单。二阶变式在 RULES 用A短循环“基础/新玩法”、B短开始、B长取消（文字明确显示）；一阶则保持前述A开始。3秒 READY 显示3、2、1，吞掉残留输入，要求两键全松再开始。不要用同一次菜单确认启动第一拍。

**所有游戏、教程、倒计时和结果页均支持双键重叠按住700ms直接回主页**。检测到双键重叠立即冻结局时与动作；不足700ms松开则显示“已暂停”，A短继续/B短回书，防止暂停期间意外扣分。暂停15秒不操作直接回书，返回前消费全部按键。游戏动作使用单键短按松开（<700ms），长按不出动作；教程说明“点按并松开”。单键长按结束可显示一次“轻点即可”，不扣额外分。按下可做球拍/轮足预反馈，但判定按松开时间，避免双键和弦先打出两次动作。

结果页默认聚焦“回到书里”，A短移动到“再玩一次”，B短确认；B长直接回书，8秒无输入回主页，最后2秒不催促。回主页恢复原模式和会话，提示“书还在这里”约1秒，不伪称纸书位置已恢复。回书所用按压不能顺便喂饭/标记。游戏期间会话相对时间继续按原契约运行，不称其为专注时长。

## 4. 五款逐项规则

### G1 一起跳绳

**关系与节奏。** 玩家是摇绳搭档，宠物自己准备跳，玩家只在绳子触地附近轻点A让这一圈顺利过去。画面角色是现有宠物，玩家用屏幕边缘两只绳柄表示。基础局固定12圈，每圈3秒，共36秒。圈起点宠物压腿，t=1.5秒出现地面白线接触提示；A松开在1.5秒±250ms内算配合成功，宠物上跳8px/240ms后落地。范围端点包含；本圈第一次A锁定该圈，重复不刷分。早按显示绳弧未到脚边，晚按/没按则绳子落地、宠物歪头，下一圈自动恢复；不减少总局长。

B在每圈前800ms内可示意“慢一点”，本圈接触时刻改为1.8秒，成功窗±350ms，总圈长仍3秒；每局最多3次，屏幕3个小空心点表示剩余，成功使用填掉一个。窗口后B不改变本圈，角落出现短横线表示未接收；不排队到下一圈。A/B都用过的圈不会产生第二次判定。≥8/12圈成功为“我们合上拍了”，否则“绳子落了，下次接上”；同样Happy/Rest短反馈，不羞辱。

**二阶实机制。** “换你跳”仍12圈，宠物摇绳。圈开始即预告低绳（地面实线→A跳）或高绳（头顶双线→B蹲），中间线只作倒计时；接触仍1.5秒±300ms，错键算本圈失误。序列固定种子生成，每局低/高各6，不连续超过3种相同；这一变式没有慢拍次数。差异是读动作选跳/蹲，不能只换成年贴图。

**局部状态。** PREPARE→CUE→WINDOW→HIT/MISS→RECOVER→下一圈/RESULT。晚帧跨过窗口无输入判MISS一次，不多算圈。**最小资产**：复用Idle/Press/Rebound/Happy；绳弧4相、地面线与上下箭头用绘图原语；蹲复用Press，不新增角色帧。**验收**：12圈时长；±250ms端点与端外；首击锁定；慢拍3次上限和800ms边界；二阶A/B对应；退出不生成照料。

### G2 羽毛球对打

**角色与球路。** 宠物在上半场，玩家是下半场球拍，不让玩家控制宠物两边。场地左右接球点x=35/100；宠物中心y=58，网y=111，玩家接触y=166。羽毛球白点配3px尾，来球轨道在起飞即用虚线预告，临近接球变实线，不能依赖颜色。A左/B右；球拍平时在中间，选键在松开时瞬移到对应侧，不要求同时移动与挥拍。

基础局40秒：每球从宠物发出到下方接触1.2秒，接球窗±250ms，首次松开锁定本次接球；对侧/窗外/未按记宠物1分，350ms歪头后重新发球。接球窗口于发球后1.45秒关闭再统一结算（早命中先保持接球姿态），接住后自动沿同轨回飞1秒；宠物固定在每第4次成功回球时漏接，玩家1分，其余接住继续；规则在教程以“看准落点，等它露空”解释，不宣称真人AI。下一球发出前停顿450ms。宠物追球动作与漏接位置先由规则确定，不能事后因玩家临近胜利突然作弊。

**二阶选路。** 回球成功后出现600ms方向选择窗，A左/B右发回；不选默认原轨。回球飞行900ms，宠物一次跨场需1100ms，若回到它所在侧可接；打到异侧则追不到，玩家得分。对手发球前用空心站位标识下一回合起始侧，固定左右交替；玩家须先接再观察选路。首个接球动作不能复用为选路，要求再次全松后新输入；选路首击锁定。这个确定性可读对手是首版取舍，后续难度不能无提示缩窗口。

40秒一到结束，不延长到下一分；截止时未判定球作废且不计漏接，屏幕给“这球下次接”。玩家分>宠物分为“这一局你赢了”，相同“打成平手”，低于“它接住更多球”；另显示“最长来回 n”，不记录排行榜。0:0仍平手。**局部状态** SERVE→INBOUND→RETURN_CHOICE(二阶)→OUTBOUND→PET_HIT/POINT→SERVE。**资产**复用Idle/Happy/Press，1个8×8球拍、1个5×5羽球、虚/实轨迹与网线，球拍左右镜像；不要缩小宠物脸。**验收**左右各10球命中/错侧；早晚与首击；基础第4成功回球漏接；二阶同侧/异侧与超时；40秒末无扣分；比分只在POINT增加一次。来球左右按seed生成、每连续4球左右各2，不能读取玩家未提交输入来改落点；基本回球落点的宠物动作可用水平线性插值，视觉位置不替代规则判定。

### G3 敲敲回声

宠物敲左/右两块小木片，玩家等它敲完再回应。40秒固定5轮，每轮8秒：前2秒展示（事件间隔600ms，2或3拍），2–3秒“轮到你”，3–6秒接收答案，6–8秒双方回应。第1–2轮2拍，第3–5轮3拍。显示期按键只给边框轻闪，不进入答案，不扣分。回答期A=左、B=右，依次比对；只比较顺序不比较速度。满N拍即锁定；错拍/超时本轮MISS，宠物重演正确两/三拍，不重开本轮。≥3/5轮正确为“我们接上了”，否则“再听一遍也好”。不显示智力/记忆能力评价。

二阶轮流作曲也是5×8秒：0–2秒玩家输入2拍（不足补A并以空心点标明补位），2–4秒宠物以600ms间距回放两拍并新增一拍，4–7秒玩家输入3拍，7–8秒回应；新增拍按seed规则，无外部模型。玩家输入真正决定后续序列，不是随机动画。长按不连发，密集按键最多N拍，多余输入直到下一轮全松才恢复。

**状态** DEMO/COMPOSE→TURN_CUE→ANSWER→RESOLVE。**构图**宠物在上方，左右木片在y=130，底部最多3个答案空心格，当前格实白。**资产**Idle/Press/Happy，木片2个矩形和敲击短线2相。**验收**展示期不录入、回答边界、短序列/超长输入/超时、二阶补位可见且回放确实来自玩家、5轮40秒稳定。

### G4 接住书签

宠物把一枚书签从上方递下来，玩家移动下面小托盘接住。不是标记真实书页，不调用阅读标记函数。36秒12枚，每枚3秒：前600ms宠物指向左或右，随后1.8秒直落，接触时刻t=2.4秒，最后600ms庆祝或落地。A选左，B选右，松开立即生效；托盘保持上次位置（首枚居左），可在接触前改选，但接触点仅采样一次，t=2.4秒同帧输入先更新位置再判定。没有手速加分；为了让不按也不稳赢，序列左右各6、最多同轨连续2枚。

接到≥8/12为“接住这一小摞”，否则“散了几张，一起收好”；漏接书签在画面底部停300ms后收走，不损坏宠物/任务，也不生成待清理。二阶保留同规则。**状态** POINT→FALL→CATCH/MISS→CLEAR。**构图**32×32宠物上方中央，轨道x=35/100，托盘宽24px、y=170；书签6×10px与羽球圆点明确区分。**资产**Idle/Mark的角色部分须去除原确认语义：首版直接用Idle+指向线，不调用Mark成功提示；书签和托盘用原语。**验收**静置最多接6枚；12枚两轨均等；2.4秒判定先后；连按不增枚数；接书签不新增 reading markers；退出无清理状态。

### G5 一起修桥（二阶）

玩家替换桥块朝向，宠物沿路线试走。48秒3关，每关16秒，关内不是限次数试错：前12秒可安排当前缺口，后4秒演示试走与复原。每关有3个缺口，依次高亮。A短按将当前L形桥块顺时针转90°，B短按放下并验证；正确才进入下一缺口，错误显示入口/出口不连的断口300ms后继续同一缺口，倒计时照常。放错不扣宠物生命，不允许狂按B绕过验证。12秒时未完成则本关未通；4秒内宠物只走已连通段，停在缺口招手。完成2/3关为“一起走过去了”，否则“桥还差一点”；不能叫现实任务完成。

首版是固定路线而非自由寻路。3关各3个独立L形连接，正确方向序列分别[0,1,2]、[3,2,1]、[1,3,0]。方向0连接上/右、1右/下、2下/左、3左/上；每个缺口的固定两端按此配置绘制白色端口，玩家用方向连接两端；三块以细线连接成示意路径，不模拟重力。每块起始方向=(正确方向+1)%4，保证必须调整。所有端口和编号可见，不靠猜隐藏答案；已放块不能改。完成提前则展示宠物休息等待下一关，不把剩余时间兑换分数。

**状态** BOARD→ROTATE/VALIDATE→NEXT_GAP→WALK→NEXT_BOARD/RESULT。**构图**3个28×28桥块置于x=20/80/20、y=66/106/146，宠物32×32位于当前桥段外侧，路径避开角色；试玩需验证135px宽度是否足够读连接，若不清楚改为单缺口放大而不缩字。**资产**现有Idle/Rebound/Happy；L块、端口、路径、选框均原语，4方向预计算。**验收**每个正确方向唯一；错误B只验证不前进；300ms内连按消费；12秒编辑/4秒演示边界；完成3段才过关；3关48秒；一阶不能从菜单/恢复状态绕入。

## 5. 显示、动画与固件接口

整屏135×240，黑底白线，无灰度必需信息。顶部y=0–27放游戏名和剩余秒数；y=32–185为场景；y=190–239两行操作/退出提示。中文优先12px（每行≤9字，实际以固件字体测宽为准），数字≥12px；不放长段落，不用仅1px闪点指示重要窗口。轨迹/目标线至少2px，命中用实白圈、失误用断线，不能只靠短闪。反馈300–600ms、屏幕不整屏闪烁；默认静音、不要求振动。

现有宠物32×32 1bit、2阶段×6状态×2帧，3072字节；跳绳可2倍64×64，其余按1倍32×32保持像素原形。资产接口仅选帧，不写成长。新素材以几何原语为主，若缓存球拍等位图，按不超过16张16×16 1bit（512字节）估算；此为预算不是测得值。既有135×240 RGB565缓冲理论64800字节，优先复用一个canvas，不为五款常驻分配五个屏幕缓冲。目标输入轮询≤10ms、渲染20fps；实板帧时、RAM与窗口舒适度待测，不以该目标声称已达成。

建议独立 `MinigameController` + 5个纯逻辑模块，固件 owner 选择具体路径；本次不创建工程占位代码。接口：

```text
enter(gameId, variant, entryStage, seed, now) -> Session
handle(LogicalEvent{key, releaseTime, shortPress})
tick(now) -> RenderModel / RoundResult
render(RenderModel, sharedCanvas)
exit(reason) -> discardSession
```

Controller持有输入域：HOME / REVIEW / MENU / RULES / READY / PLAY / PAUSED / RESULT / WAIT_ALL_UP。先仲裁退出和双键，再派发到当前域；同一输入只消费一次，跨域后直到全松不派发。REVIEW维持原A翻页/B退出，不从回看内部新增双键菜单。每帧顺序：采样去抖→和弦/退出→到期边界→本域动作→局部判定→渲染→非阻塞USB；窗口内事件按releaseTime判定，不按渲染帧时间。G4同毫秒输入先于接触；局截止时间输入一律不再计分。所有区间除明确命中窗外采用[start,end)。

时间采用uint32差值，暂停时累计activeElapsed；游戏时长不含规则、倒数、暂停。若调度停顿>150ms，在推进游戏前暂停并提示“准备好了再来”，A恢复且重新预告当前未决回合，回合已得分不重算；不让USB阻塞造成无提示连续失误。暂停恢复重置该未决回合起点，其局时也退回该回合起点一次；每回合最多自动恢复一次，第二次卡顿直接回书并提示“先休息一下”，避免永不结束。真实固件能否满足时序由owner验证。

游戏无需网络、无游戏USB命令、无Agent判断胜负。不主动写NVS；关机/复位丢弃局内进度，不恢复半局，不损失现实节点。存储异常由原模块处理；返回主页保留原保存失败提示，游戏不覆盖故障状态。后续死亡/重开协议尚未定义：不自行复活、不改变死亡规则；若上游明确宠物不可互动则退出游戏，由上游状态页接管。

## 6. 可复用验收与派单边界

首批工程拆分：①仲裁/输入域/菜单与结果页 ②G1及确定性单测 ③实板手按与读屏 ④G2及对手规则 ⑤双游戏成长隔离回归。之后G3、G4、G5各独立提交，不与节点存储迁移混在同一提交。

| 验收层 | 必须得到的证据 |
|---|---|
| 输入单测 | 单A/B 699/700ms互斥；先A/先B/同时、短重叠/长重叠；菜单/退出按压无业务漏出；松开跨状态；去抖与millis回绕 |
| 规则单测 | 五款各自端点、未操作、乱按、重复判定、到期、seed复现、暂停重开未决回合；固定测试时钟，不等真实40秒 |
| 隔离回归 | 开局前后对比completed_nodes、去重表、care、markers、mode；游戏1000局保持一致；合法任务确认期间仍幂等增长一次且下局解锁 |
| 手持实板 | 真A/B进入→规则→一局→回书，双键舒适性、32px脸可认、虚实线可见、字不裁切、连续10局不卡顿；证据不可用注入代替 |
| 异常 | 断USB离线可玩、重连不重播、复位不扣成长、低电/存储错误仍能退出；串口测试由唯一固件owner执行 |
| 产品体验 | 自愿短试玩记录是否理解“我在和宠物做什么”、是否主动回书、是否误标记、手持不适；观察与口述分别记录，不解释为提升注意力 |

共同活动价值是假设：跳绳来自互相等节拍；羽毛球来自对手可读回应；回声二阶来自宠物复述我出的内容；修桥来自宠物实际走我搭的路线。书签主要是接物反应，关系价值较弱，若测试只记住分数先砍它，不加奖励挽救。可在小规模内部试玩中比较“保留分数隐藏宠物回应”和“隐藏分数保留回应”，询问愿意留下哪版；这是探索，不做科学效力或注意改善结论。阅读中不弹游戏，原主任务出入须由用户主动决定。
