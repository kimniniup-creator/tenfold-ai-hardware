# 原创机械独立结论

首打推荐：**环轨 Orbit-10 的普通 PLA 光滑版，不装钢珠与弹簧**。冻结几何7a370bc0a7f229ff0cf9a87dcb91861b34325723。五个功能塑件、四颗M3螺钉及四螺母，无打印弹性卡扣，数字检查与实际切片支持进入校准/试打；不是实物可靠性或手感认证。

先打印四个校准件，再按作者README打印五件，干装后才装M5。四颗M3沉头螺钉实长29.7–30.0mm、头径≤6.0/高≤1.7、末端不完整牙≤0.5；螺母对边≤5.5/厚≤2.4。最坏完整牙重叠2.2mm是尺寸链计算，不是强度测试。去毛刺后旋转一整圈、全姿态保持和自己的USB线插拔均须明日实测。
