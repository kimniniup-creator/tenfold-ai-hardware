## 工具与证据

PrusaSlicer2.9.6官方签名程序，通用PLA0.4喷嘴/0.2层高/4墙/25%填充，配置generic-pla.ini。每件STL按作者方向单独切片，CLI落床，G-code留.local；不向用户提供未经机型匹配的G-code。audit_print.py锁Git SHA归档后直接读STL，闭合/绕向/连通/体积、512个固定种子法向厚度样本、实际切片、层数与挤出路径。法向厚度样本不是全局最小壁厚证明，也不能直接把倒角薄楔当制造失败。

官方M5 STL三装配分量0/3/4独立量得约24×48×15；其余为散放重复件。m5-reference.json记录来源/哈希/边界，原厂网格不再分发。端口操作仍需要具体几何与实机分别判定。
