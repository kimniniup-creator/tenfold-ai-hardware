# 原创数字制造与APK验收门

每个候选锁完整SHA，先读源码/BOM/打印指南，复制提交到独立快照，再导入实际STL/STEP、执行生成、实际切片。不能以旧适配稿的问题给原创模型判失败，也不能把“原创”当可制造证明。

## 数字试打门

1. STL闭合、绕向、连通数与正体积；STEP实体数和有效性；每种件数量与装配一致，运动件不能意外融为一体。
2. 最薄设计壁/杆/卡扣由源码定位；抽样法向射线仅辅助发现薄区，不称全局最小厚度证明。0.4喷嘴下路径缺失或单线承力薄区必须定位处理。
3. 按作者提供朝向实切片；检查落床、空层、桥接、支撑体积与支撑能否拆出、孔内支撑和层向。工具通道与装配顺序要允许装入每个被捕获运动件。
4. 全行程/旋转/容差极限、硬限位、脱落路径、五金头母垫工具、螺钉长度链；不以静态不相交替代运动验证。
5. M5官方结构/尺寸证据及具体安装姿态：USB线壳、KEY1/2、屏幕、reset/Grove/HAT可达分别列明，不以总包络通过接口。
6. 可独立先打印校准件：孔/轴/滑动间隙/卡扣（如有），材料和装配工具齐全。先校准再全件；PLA弹性件寿命/脆断不能用数字模拟背书，PETG替代应给重新校准条件。
7. 选最可靠首打方案，说明淘汰/备选理由；不承诺三套全部能用。只有实打后才能验收手感、保持力、寿命、真实配合。

通用筛查配置generic-pla.ini：0.4喷嘴、0.2层高、PLA、4墙、25%填充；机器未知，所以切片G-code仅留.local，不作为用户上机文件。可交付STL/几何3MF及对应打印指导，让用户在实际机型配置下重新切片。

切片器：官方PrusaSlicer2.9.6 Windows zip，SHA256 5aaf22e42f95accecfa122d23a835911f289ecc2ff606db3e83d637ddcc0a209；console程序Authenticode签名Valid，签署者Prusa Research a.s.。
来源：https://github.com/prusa3d/PrusaSlicer/releases/tag/version_2.9.6 。使用实际--help/--help-fff核实CLI选项。

## APK与板端（产出后锁SHA）

- APK包名/minSdk/签名/可安装；真实启动、创建动作、确认、完成/重复提交、封存/恢复、进程重启持久化。
- 模拟与真实USB明确分离；未连接不能显示成功；只接受支持设备，权限回调与拒绝路径。
- USB CDC初始化、OUT和IN、分片/合包/超时、ACK正确关联、断连重连和序列幂等。
- 固件严格JSON解析而非substring；未知命令/坏字段不改状态；持久化成功后ACK、断电恢复、板上按键。
- Android模拟器通过不代表板端成功；无真实M5时板端USB/按键/音码/重启链路保持NOT_TESTED，不能用编译结果替代。

设备租约：软件任务与测试者先协调，避免同时控制同一模拟器/真机。当前adb devices为空。
