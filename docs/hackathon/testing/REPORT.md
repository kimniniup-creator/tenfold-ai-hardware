# 三版附件独立工程测试

日期：2026-09-22。结论：三版均不能通过完整 EDC 验收。网格有效仅证明附件数字几何成立，不证明真实适配、可打印装机、保持力或机械减压体验。

## 范围与复现

基线：针板 `9617a85`、按压旋转 `5671da9`、球式 `9591aa5`。测试从 Git 提交归档到测试者独占 `.local/audit/<SHA>`，读实际 STL / STEP，再执行归档的 build.py；不改作者工作区，不依赖作者 JSON 判定网格。精简证据见 evidence.json、probes.json。原始构建日志留在忽略目录，不上传可再生图片/模型。原 PRD / IMPLEMENTATION / INDUSTRIAL_DESIGN 已读；本轮允许屏幕、体积和十珠降级，但不删除真实机械体验。

PASS=仅列明的检查成立；FAIL=已有反例；BLOCKED=缺必需源几何/设备信息；NOT_TESTED=尚未执行相应物理或工艺测试。所有尺寸单位 mm。

球式锁定 `8ba49f0d8c56d5c531611860dcf0996722f94a82`：独立归档后默认60重新生成退出0，实际STL网格/体积/边界指标与提交一致。50及80分别在测试者目录重跑，退出0，两件均闭合单连通，重新执行的硬件/工具对塑件/M5/球包络最大相交0。见ball-retest.json和ball-range-retest.json。基线条件探针把OD7/H0.5垫圈放在柱底Z3，四处均与底板相交约5.04804mm³；新D8凸台和下垫圈Z=-0.8..0消除这个反例。T-BALL-02在指定光滑紧固件/直线工具包络范围关闭；实物螺纹、预紧、采购误差仍NOT_TESTED。T-BALL-03补充grip.png已看，端点已复跑，文档/参数检查关闭，人体工学不随之通过。T-BALL-01保持FAIL，取球后与电子件分离的问题未解决。新螺钉端Z=-6.2、头顶26.8，原23mm附件高度不能再当含五金高度。

## 产品能力边界

机械被动触感来自原玩具；当前附件没有主动触觉马达。M5按键能表达明确意图，IMU的整体运动不能替代原针阵/旋转/内层位置检测。屏幕十格为设计降级，不是十枚机械锁存。固件、BLE、语音与扬声器业务反馈未在本次CAD测试中验收。交互映射以docs/hackathon/product的最新产品文件为准，三模型README旧映射不是权威。已将关键发现同步PM和验收任务，禁止用附件CAD完整替代产品通过。
