# 证据与替代方案

核对日期：2026-09-22。产品定向检索，非系统综述。以下都是机制依据或反例，不是本产品效果证据；没有参与者实验、留存或专注提升数据。摘要未给出的样本量、效应量和置信区间不补写。

## 直接相关的原始研究

| 研究与可点击来源 | 本轮读到什么 | 可以支持什么 | 不能支持什么 |
|---|---|---|---|
| Trafton、Altmann、Brock、Mintz（2003），[Preparing to resume an interrupted task](https://doi.org/10.1016/S1071-5819(03)00023-5)；[出版者页面](https://www.sciencedirect.com/science/article/pii/S1071581903000235) | 出版者搜索返回的完整摘要；直接打开403，未读方法全文。实验比较8秒中断预警与即时中断；预警组更多准备、恢复更快；即时组随练习改善 | 中断前准备是可检验的恢复机制 | 不证明自动生成卡、EDC或8秒固定交互有效；实验准备行为不能等同我们的产品。样本与效应量未核实 |
| Leroy、Glomb（2018），[Tasks Interrupted / Ready-to-Resume](https://pubsonline.informs.org/doi/10.1287/orsc.2017.1184) | 出版者摘要，四项研究；预期恢复时有时间压力与注意力残留有关，短暂规划回来可缓解 | 留下恢复计划可能帮助转换任务 | 主要关注**中断任务的表现**，不能误说测得返回原任务速度；未精读全文、未核实各研究样本与效应量 |
| Gilbert（2015），[Strategic offloading of delayed intentions into the external environment](https://pubmed.ncbi.nlm.nih.gov/25404057/) | PubMed摘要；四个在线实验合计N=1196，外部提醒支持延迟意图完成 | 把未来要做的事外置是合理机制候选 | 短时网页任务不等于复杂工作；不证明LLM整理优于自己写，亦非EDC试验 |
| Stothart、Mitchum、Yehnert（2015），[The attentional cost of receiving a cell phone notification](https://pubmed.ncbi.nlm.nih.gov/26121498/) | PubMed摘要；未直接操作手机时，通知也干扰注意任务表现 | 默认静默、避免主动提示有研究动机 | 不推导每种通知同样有害，不推导硬件通知天然更好；未核实全文效应量 |
| Leroy（2009），[Why is it so hard to do my work?](https://doi.org/10.1016/j.obhdp.2009.04.002) | 本轮出版者题录核对成功，正文/摘要直开403 | “注意力残留”的原始文献定位 | **不以本轮未读正文新增定量结论**；主要机制表述以已核对2018摘要为限 |

因此我提出的因果链是待验证推断：用户保存停点与下一步 → 少一点重新搜索/回想 → 更快做出与原任务有关的有效动作。研究没有证明这条产品链已经成立，也没有证明“知道下一步”足以解决所有专注问题。突然中断、卡过时和建卡成本都可能让它失效。

## 已有11篇论文如何使用

本轮完整读取仓库[既有11篇证据矩阵](../../../research/pixel-companion/papers/EVIDENCE.md)，并阅读其产品判断与交接；未重新逐篇下载或宣称重新精读全文。

| 既有编号 | 本次结论 |
|---|---|
| P1 按键/情绪 | 多键固定任务的实验不能变成单按钮注意力分类器；频率只说明发生了操作 |
| P2 fidget球随机试验 | 焦虑/生理未见显著组间优势，不证明全部把玩无效，也不支持专注提升 |
| P3 触觉抱枕 | 特定触觉与焦虑终点；不外推到M5屏幕、恢复卡或生产力 |
| P4/P5/P6 呼吸实验与综述 | 剂量、终点与当前任务不同；不进入专注路演主证据 |
| P7 HRV反馈 | 本机无相应传感器；不能把按键间隔当生理反馈 |
| P8 Purrble开放试验 | 可能存在接受度与内疚/过度刺激负担；不能把陪伴效果当专注效果 |
| P9 Fidget Widgets（35人调查/原型） | 支持研究低视觉负担、自由把玩；没有证明生产力提升 |
| P10 Touchable Comfort Objects（132人调查） | 提醒携带、个人意义与不需交互的重要性；不等于EDC市场或因果效果 |
| P11 Fidget Knob（6人探索） | 把玩模式受个人与主任务影响；更不能把点击增加翻译成分心 |

P9–P11仅用于设计约束。若需要对外引用具体数字，先回到矩阵对应原文与阅读深度，不能把本表当独立复核。首轮不做医疗、情绪诊断或fidget专注疗效宣传。

## 标题边界

[Vaswani等（2017）Attention Is All You Need](https://arxiv.org/abs/1706.03762)提出Transformer序列建模架构。本轮核对原始摘要。标题可作为AI时代重视人的注意力的隐喻；“机器的attention”与人的注意力不是同一科学构念，不用于本产品效果论证。
