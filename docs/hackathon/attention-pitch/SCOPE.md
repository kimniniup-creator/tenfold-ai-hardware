## 变化清单

| 项目 | 当前像素方向 | 注意力提案 | 对owner的影响/建议动作 |
|---|---|---|---|
| 目标 | 自由按压与轻陪伴 | 一次中断后的任务恢复 | 需要确认价值方向与首用户；不能只换宣传文案 |
| 输入 | presses/held_ms/mean_interval_ms | 用户选定任务文本、停点、来源、修订 | 新增主机文本入口与云同意；现有节奏无法提供语义 |
| Agent决策 | 选择有限回应与动画 | 判断缺项/冲突、候选卡、用户确认、工具状态 | 新增schema/来源/版本；不是换system prompt即可完成 |
| 触发 | ≥3次按压候选、60秒冷却 | 明确主动建卡；取回不调模型 | 取消以把玩次数触发专注建议；不得保留旧逻辑后宣称主动触发 |
| 设备交互 | A动画，B安静 | A自由把玩；专用动作取回；B退出/静默 | 需重做长短按与误触验收，现映射仅提案 |
| 通信 | 窗口/session/epoch短句回复 | 持久化卡、revision、ACK、缓存与恢复 | 旧会话失效逻辑可借鉴，旧telemetry无历史不能替代任务存储 |
| 输出 | 五条固定陪伴短句 | 用户确认的短卡及来源时间 | 新显示需求；真实字形/溢出需实机核对 |
| 原任务恢复 | 不涉及 | 主机手动回原任务/用户点击可信入口 | P0不自动打开全套应用，不读全屏 |
| 硬件 | M5原生设备；实机门未过 | 沿用M5，默认静默，USB桌旁验证 | 不恢复机械外壳、麦克风、震动、COM9操作或无线开发 |
| 成功指标 | 交互与回应可靠性 | 恢复耗时、质量、非必要切换、负担 | 需用户试验；点击/喜欢不算效果 |

## 最小实施候选，非已授权派单

建议产品owner将下列范围合成一次取舍：本地卡输入与保存、受控Agent候选和确认、设备卡同步/取回、失败退出。这四部分是一条闭环；如果只有“按键→一句鼓励”，仍是旧产品，不能改名为注意力Agent。

验收需要：真实模型与表单来源可辨；用户取消后迟到结果无效；原文不被编造为已完成；保存失败保留旧卡；断连重连不覆盖新revision；真机取回显示正确短卡；恢复原任务的动作可完成；没有卡不报成功。性能与隐私细则见[机制](MECHANISMS.md)。

未来愿景单列：授权读取选定IDE/文档上下文、用户选择时批量处理支线、用户主动缩小卡点、无线随身。自动判断分心、按压情绪分类、聊天陪伴、排行榜和专注分数不纳入。

产品owner需决定是否将B升级为需求以及黑客松时间内能完成哪一级；在此之前路演按提案版，保留真实进度。直属创建任务负责与产品协调交换综合结论；本任务不自行联系工程或改其PRD。
