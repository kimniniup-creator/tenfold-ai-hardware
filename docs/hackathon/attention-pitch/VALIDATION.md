# 最小对照验证：分别证明卡、Agent与硬件

状态：待执行方案，无受试者数据。8名目标用户为可用性探索样本，不是统计功效计算，不能用“显著/不显著”判断普适疗效。先招经常在代码/文档/AI会话间工作的成年人；不招募临床人群来暗示治疗定位。

## 第一轮：2×2交叉试验

每人四个难度匹配的虚构资料核对任务，每项包含一次预先允许留卡的中断。每项工作约6分钟，中断约90秒，回来继续约3分钟；另有教学和休息，合计约50分钟。卡输入和生成时间真实计入，不把准备成本藏到任务前。每人经历全部四条件；用拉丁方平衡顺序，8人覆盖两轮四种顺序，任务材料与条件轮换，避免反复做同题记住答案。

| 条件 | 相同部分 | 唯一变化/要回答的问题 |
|---|---|---|
| A 软件+手填卡 | 相同三字段、原任务入口、离线存取 | 最便宜基线，快捷键取回 |
| B 软件+Agent卡 | 与A相同保存/显示/确认流程 | 用户给零散停点后Agent整理，含网络延迟与修订；检验Agent增量 |
| C EDC+手填卡 | 与A相同卡和主机输入 | 取回入口换为设备，检验硬件增量 |
| D EDC+Agent卡 | 与B相同生成和输入 | 比B看硬件增量，比C看Agent增量；不能只拿D比A就声称各部件有效 |

第一轮统一禁用装饰动画和声音；C/D必须使用同固件、同字数上限，A/B也先显示同样短卡并保留全文入口。默认关闭主动通知。不要让软件组只能联网、硬件组能离线，或故意增加软件解锁步骤。

## 第二轮：最低成本替代

若第一轮显示硬件可能有增量，同一批用户另测“普通熟悉EDC+软件手填/快捷键”和“集成EDC+手填”，匹配任务与顺序，区别只在取回入口。加入一次无卡常规恢复作探索基线，测卡整体是否值得成本；不据第二次熟练后更快直接归因硬件。样本负担过大则分日进行，不能删掉对照只保留最漂亮结果。

手机App用相同卡与本地能力作后续对照；目前没有新机制手机版本，不能伪造已采集的手机数据。无线随身、长期携带及自然工作表现也需后续测试，USB桌旁结果不能代替。

## 指标与采集

| 指标 | 明确定义 | 数据来源/当前缺口 |
|---|---|---|
| **主要：恢复耗时** | 中断任务结束信号到第一个经评分规则判为正确、与原任务相关的动作；打开卡/窗口本身不算 | 同意后屏录或观察时间戳；目前没有采集。3分钟内未恢复记为右删失/未恢复，不能排除后只算成功者 |
| 总成本 | 建卡输入+等待+修订+恢复耗时；保留各项，不仅汇总 | 主机事件与人工观察交叉核对；等待中继续工作要另记，避免双算 |
| 非必要切换 | 恢复窗口中与预先定义任务无关的应用/页面切换次数；查资料等必要切换不罚 | 两名评阅者按任务规则标注分歧；设备按钮日志不能观测电脑切换 |
| 任务质量 | 预先确定的正确判断/错误数、遗漏数；评阅者尽可能不知条件 | 交付答案/任务记录；更快但质量下降不判成功 |
| 负担/干扰 | 建卡修改次数、抬眼看设备次数、误触/重复事件、1–7分费力/打扰自报、手部不适与退出原因 | 观察+短问卷；不同尺度不合成伪精确专注分 |
| 可靠性 | 确认保存后能取回正确revision的比例；云失败/断连次数 | 需要新增任务事件日志；当前节奏telemetry会丢弃且不持久化，不能直接使用 |

最小日志提案：匿名participant_id、condition、task_id、card_revision、input_start、confirm_at、persist_ack_at、interruption_end、retrieve_at、first_correct_action_at、cancel/error、质量结果。按键次数只用于可靠性/误触分析，不进入效果分数。人工判断正确动作是必要标注，不由模型自评。

## 预先约定如何做产品取舍

先看每个人的配对差与分布，再报中位数和原始范围，不给8人结果加伪精确显著性叙事。工程失败留在分母并单独说明，不删除低表现用户。语义生成分为“短而明确”和“零散复杂”两类描述性分析，避免事后只挑Agent占优子群。

探索性继续门（产品选择阈值，非科学标准）：至少6/8人在目标复杂任务上恢复更快且质量不下降；Agent的建卡+恢复总成本相对手填中位数至少减少10秒，且不增加错误事实；硬件相对同内容软件至少减少一次不必要回主机动作，误触不增加且主观打扰不更高。若任务本来不足10秒改善空间，先调整任务适配性，不能降低门槛来宣布成功。

该门仅决定是否值得下一轮；不支持“提高专注X%”。若硬件只在离桌情境占优就收窄定位；若普通EDC+快捷键一样好，取消集成硬件增量主张；若手填一样好，移除Agent。突然中断与完全无卡的场景单列失败边界，后续自然使用3–7天记录卡是否过时、是否愿意继续留卡及新奇效应。

参与者可退出，先同意才录屏；只用虚构任务与匿名编号，录屏/原始个人资料不进公开仓库。无法录屏时用观察计时，报告测量误差；不能拿模拟日志替代观察结果。
