# Tenfold 十日机械盘｜外观与工业设计规范

版本：v2
状态：外观方向锁定，工程细节待验证
锁定日期：2026-08-03

## 1. 设计意图

Tenfold 不是缩小的智能手表，也不是带灯的钥匙扣。它是一件会让手主动拿起、旋转和按压的精密机械 EDC：像高级腕表机芯一样克制，像随身把玩物一样有惯性和反馈，同时把十日进度直接做进结构。

外观的第一判断标准不是“看起来功能很多”，而是：

1. 一眼能数出十枚日珠；
2. 一只手能理解中央旋转与外围按压；
3. 放在桌上像高端工具，拿在手里像收藏级 EDC；
4. 没有屏幕、麦克风开孔、钥匙圈或廉价灯带感。

## 2. 锁定的外观 DNA

以下属于产品识别，后续结构设计不得随意取消：

| 项目 | 锁定定义 |
|---|---|
| 外轮廓 | 软化倒角的十边形，避免正方形轮盘或普通圆形硬币感 |
| 正面层级 | 外框 → 深色内环 → 十枚日珠 → 黑色中央旋压轴 |
| 日珠数量 | 严格 10 枚、等距 36° 分布、正面完整可见 |
| 状态表达 | 已完成日珠下沉约 1.2–1.5 mm；当前日珠呈酸性荧光绿 |
| 中央轴 | 黑色高光 / 细密同心纹，兼具旋转、按压与把玩惯性 |
| 主材质感 | 微喷砂金属外框 + 烟灰色内环 + 陶瓷或类陶瓷日珠 |
| 正面信息 | 无文字、无数字、无品牌大标、无可浏览屏幕 |
| 携带方式 | 口袋与桌面优先；充电和挂载结构隐藏在背面或底座 |

## 3. 尺寸与比例目标

| 参数 | 目标 | 工程容差 / 说明 |
|---|---:|---|
| 最大宽度 | 46 mm | EVT 可在 44–48 mm 内调整 |
| 最大高度 | 46 mm | 保持近似正十边形视觉 |
| 总厚度 | 14 mm | 工程上限 15.5 mm；超过需重新做握持评审 |
| 外框圆角 | 1.2–2.0 mm | 不割手，同时保留精密切面 |
| 单枚日珠可见直径 | 6.8–7.6 mm | 必须保持十枚可清楚计数 |
| 日珠下沉行程 | 1.2–1.5 mm | 盲摸可辨；不应形成夹手缝隙 |
| 中央旋压面直径 | 17–20 mm | 拇指可稳定旋转和按压 |
| 目标重量 | 铝版 55–80 g；钛版 80–115 g | 由内部堆叠与重心验证修正 |

目标重量不是越重越好。产品需要有金属惯性，但不能在口袋里成为负担，也不能跌落时产生过高冲击。

## 4. CMF

### 标准版

- 外框：6061-T6 或 7075 铝合金 CNC，细喷砂 + 深灰阳极。
- 内环：烟灰色 PC / PMMA 光学件或 PVD 金属件，隐藏状态光。
- 日珠：石墨灰陶瓷帽或类陶瓷复合材料；表面微哑光。
- 中央轴：黑色陶瓷帽或不锈钢 DLC / PVD，细密同心车纹。
- 状态色：`#BCFF38` 附近的酸性荧光绿，只出现在当前日珠和极少数 UI 强调。

### 高配版

- 外框：Grade 5 钛合金 CNC + 微喷砂。
- 其他视觉比例不变，不使用花哨大马士革纹作为默认款。

### 当前日珠如何变绿

量产方向应优先采用“十枚烟灰半透日珠 + 单枚低亮度绿光”而不是固定一枚绿色实体珠。这样当前日期可以在十个位置移动，同时静止时仍保持机械而非电子玩具感。渲染图中的绿色日珠代表发光后的视觉状态。

## 5. 交互语义

| 动作 | 物理反馈 | 产品语义 |
|---|---|---|
| 旋一下中央轴 | 磁性棘轮 / 惯性旋转 + 短震 | 我回到当前项目 |
| 按下当前日珠 | 清晰段落感，日珠锁定下沉 | 今天完成，不再追加 |
| 长按中央轴 | 一次较长震动，绿光熄灭 | 进入 Seal，今晚停止 |
| 双击中央轴 | 两次柔和震动 | 进入 24 小时恢复窗口 |
| 新周期复位 | 按住中央轴并逆时针旋转复位环 | 十枚日珠全部弹起，开始新周期 |

“按住中央轴并逆时针旋转复位”是当前推荐机械方案，不属于最终锁定动作；结构样机可提出更可靠但同样克制的替代方案。

## 6. 结构分层建议

```text
陶瓷日珠 / 中央帽
        ↓
十枚独立锁定柱 + 中央轴承 / 磁性棘轮
        ↓
复位凸轮环 + 导光环
        ↓
按键 / 位置检测 PCBA + LRA
        ↓
BLE/NFC 主板 + 电池
        ↓
金属底壳 + 隐藏充电触点 / 桌面底座
```

结构必须让机械载荷通过骨架传递，不能让用户按压直接压在 PCB、焊点或电池上。

## 7. 人机与安全要求

- 单手拇指可覆盖中央轴与至少相邻三枚日珠；换握后可覆盖全部十枚。
- 不应出现可夹皮肤的开放齿轮、剪切缝或外露磁铁。
- 桌面放置时不得因中央轴突出而摇晃。
- 口袋中 20 N 局部挤压不得误完成当天；固件和机械都需防误触。
- 正常把玩声应低于安静办公室可接受水平；建立点击声的 dBA 基线后再定指标。
- 跌落后日珠不得飞出；小零件固定方式需按目标年龄和市场法规复核。

## 8. 设计验收

### 外观样机通过条件

- 正视、30° 和手持视角都能数出十枚日珠。
- 46 mm 级模型可在牛仔裤口袋、外套口袋和桌面三场景自然存在。
- 至少 8/10 名目标用户无需说明即可发现“旋转中心、按外围珠”两种动作。
- 连续把玩 10 分钟无割手、明显疲劳或结构松动。
- 与普通 fidget spinner、钥匙扣、智能手表和硬币有明显区分。

### 工程样机通过条件

- 日珠下沉高度差可盲摸识别，误触率满足 PRD。
- 10,000 次日珠循环后无卡死；中央轴 50,000 次旋转/按压后功能正常。
- 静置桌面不自转，口袋携带不自行复位。
- 外观件拆装不损伤可见面，电池与 PCB 可维修更换。

## 9. 参照与知识产权边界

用户提供的 EDC 图片与 `42.COSMO × MACKIE Life and Death Game` 高度吻合。Tenfold 只借鉴高密度金属 EDC 的单手多层触感、中央旋转、可换材质和收藏感，不复制：

- 方形轮盘比例；
- 六枚子弹及“生死”语义；
- Morse code、品牌标识、装饰纹样；
- 具体 XX Slider 盘结构或可替换配重接口。

开模前必须进行一次外观专利、实用新型与核心机械结构的 FTO 检索。本文件不是知识产权法律意见。
