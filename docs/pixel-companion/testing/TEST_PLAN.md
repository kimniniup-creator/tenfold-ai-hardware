# 像素陪伴独立测试

状态：准备完成，候选待到；COM9由软件独占，测试禁止打开。范围为M5StickS3原生按键、像素宠物、节奏摘要及Agent/bridge；不测试或制作外壳。

## 证据规则

每次锁源码commit、固件/bridge哈希、依赖版本、端口租约与板型。分开记录HOST（主机实际运行）、SERIAL（串口协议）、PHYSICAL（真实按键/屏幕/供电）。注入事件只能证明注入后的链路，不能代替GPIO去抖或屏幕观察。NOT_TESTED不是PASS。

仅产品总控01a0c5b4-a19c-7810-8c6e-d8a87bb68f70可以发COM9租约。测试不抢软件串口、不擅自烧录。观察或测试结束明确释放；开端口前再次枚举，防止重连换号。低电测试不通过危险放电制造状态。

阈值、窗口长度、频控/超时数字由产品和软件冻结契约提供，未拿到前不自行将猜测当验收标准。重点边界按阈值−1/阈值/阈值+1及计时回绕建立用例。

## 执行顺序

1. 只读端口/仓库/运行环境检查；候选源SHA和接口到达后，先执行无硬件主机反例与模拟服务失败测试。
2. 构建从测试独立快照执行，不写软件作者工作区；保存实际退出码与固件哈希。
3. 有租约后验证板型/启动标识/协议，按明确授权范围运行串口，不默认获得烧录权。
4. 真实按键、屏幕、供电只能有直接可观察输入和证据时判定；缺硬件操作能力则明确缺口并回传总控安排现场测试。
5. 报告按T01–T11逐项写PASS/FAIL/NOT_TESTED及证据路径，提交推送后回传产品总控。

## 已读产品契约（2026-09-22）

权威来源docs/hackathon/product/PIXEL_COMPANION_PRD.md（产品worktree）。产品P01–P10与本文T编号分开：

- P03→T04/T05：会话+窗口序号去重，验证计数/间隔/时长及溢出；具体窗口由软件定。
- P04/P08→T06/T08/T10：无网也能完整本地玩；界面区分本地/Agent来源，无密钥规则不得冒充模型。
- P05→T06/T07/T11：限长、动作白名单、畸形JSON及超时fallback；密钥只在主机环境。
- P06→T05/T07/T08：自动提示至少60秒冷却，一次最多一条；静置不催促，重连不重播。
- P07→T10：原创idle/blink/press/happy/rest；240×135横屏是待实板确认值；短句不得裁切。
- P09→T09：偏好适量保存、不逐按写闪存；原固件备份/恢复路径由唯一烧录owner提供。
- P10：构建、板上输入、渲染、bridge三层分别给出证据。真实LLM、物理按键手感/舒压效果不得由注入或动画推断。

已知明确禁止：情绪/焦虑诊断、责备与养成惩罚、无振动硬件却宣传振动。不将本测试补充低电边界扩大成新产品功能要求。
